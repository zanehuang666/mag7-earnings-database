# 历史资料重建：WDC [2026Q4](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm) 财报前瞻

本文仅基于上一份 SEC 文件重建，不构成实时预测，也不写本季实际结果。所给文件披露的是截至 [2026-07-03](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm) 的完整财年，而非单季：营收 [129.19亿美元](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm)、营业利润 [44.53亿美元](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm)、净利润 [94.24亿美元](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm)、经营现金流 [39.29亿美元](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm)。因此前瞻只能以上述全年规模为锚，观察存储需求、价格与产品组合能否延续，以及利润与现金流匹配度。

验证问题甲：下一季营收与毛利率能否在全年高位上保持韧性？若企业级/近线存储需求强劲、价格稳定，则正向情形是收入与营业利润同步改善；若渠道库存上升或价格回落，则负向情形是利润率承压。

验证问题乙：经营现金流与净利润的差异会否收窄？全年经营现金流 [39.29亿美元](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm) 明显低于净利润 [94.24亿美元](https://www.sec.gov/Archives/edgar/data/106040/000162828026057139/wdc-20260703.htm)，若下一季回款改善、库存下降，正向情形是现金流修复；若营运资本继续占用，负向情形是现金转化弱于利润。

结论：前瞻重点不是复述全年业绩，而是验证单季动能能否支撑利润与现金流。所有数字均来自同一官方文件。
