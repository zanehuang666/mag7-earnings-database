# 西部数据（WDC）2025 自然年一季度（FY2025 第三财季）财报后分析

**资料截止：2025-05-02 23:59:59 UTC｜报告期末：2025-03-28｜财年：公司财年 2025（6 月末结束），本季为 FY2025 第三财季**

## 主要结论

本季是一份"结构切换后"的强周期修复财报：闪存业务已剥离，持续经营仅剩 HDD 单一分部，收入同比 +31%、营业利润率跳升至 33%，利润与现金质量明显改善。但增长高度集中于 Cloud 端少数大客户（前三大客户合计占收入 47%），Client/Consumer 同比仍小幅下滑，说明这是一轮由云/AI 存储需求驱动的、而非全面复苏的行情。判断成立的前提是：Cloud 需求延续且大客户集中度不引发订单波动；若关税或客户去库存冲击 Cloud 订单，本季的高利润率难以线性外推。

## 财报数据与主要产品

- 净收入 **22.94 亿美元**，同比（上年同期 17.52 亿）增长约 31%（[10-Q](https://www.sec.gov/Archives/edgar/data/106040/000010604025000026/wdc-20250328.htm)）。
- 营业利润 **7.60 亿美元**，营业利润率约 33%；上年同期仅 0.94 亿。
- 净利润 **5.20 亿美元**。
- 收入结构（按终端市场，单季）：Cloud **20.07 亿**（上年同期 14.55 亿），Client **1.37 亿**（上年 1.40 亿），Consumer **1.50 亿**（上年 1.57 亿）。增长几乎全部来自 Cloud。
- 公司自述：因闪存分部剥离，持续经营现为单一 HDD 报告分部，CODM 按合并结果评估业绩。因此本季不再有 HDD/Flash 双分部数据。

## 利润与现金

毛利率改善是核心：收入成本占收入比从上年同期 70.4% 降至 **60.2%**，直接推动营业利润率从约 5% 升至 33%。公司解释为 HDD 供需关系改善、收入较上年同期提升，此前因减产、裁员、资产减值与产能利用不足产生的费用压力缓解。需注意：**98 百万美元衍生品未实现收益**计入当期，属非经营/公允价值性质，对净利润有正向贡献，不应视为可持续经营利润。现金流与资本开支的明细在本次节选中未完整呈现，尚待核实：需查 10-Q 现金流量表中经营现金流、资本开支与自由现金流的具体金额，以及九个月累计口径。

## 本季核心问题（无同期 Preview）

本季无同期 Preview，故不做预测复核，改写为核心问题：**闪存剥离后，HDD 单业务能否凭 Cloud 需求把利润率维持在 30% 以上？** 实际结果给出偏正面的回答——Cloud 收入同比大增、毛利率显著抬升，验证了 HDD 供需修复逻辑；但集中度风险同步上升（前十大客户占单季收入 73%，上年同期 59%），这是本季最需警惕的结构性变化。

## 下一季判断与关键验证点

倾向判断：若 Cloud 需求延续，FY2025 第四财季收入与利润率有望维持高位，但环比增速可能放缓，且大客户订单节奏会放大波动。验证点：
1. Cloud 收入环比是否继续增长，Client/Consumer 是否止跌；
2. 毛利率能否守住 60% 成本占比附近，衍生品收益是否逆转；
3. 前三大客户集中度是否进一步上升；
4. 关税影响——公司称截至第四财季初未受重大影响，但已提示可能通过供应链调整或提价对冲，需跟踪实际成本传导；
5. 经营现金流与资本开支（本次未获取，需查现金流量表）。
