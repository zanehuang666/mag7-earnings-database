# 三星电子（SMSN）2025Q4 财报分析：存储业务推动单季营收与利润双创新高

**无同期Preview说明**：本季财报发布前没有可用于复核的同期分析文章，因此本文不设预期差对比，仅整理官方财报信息。所有数据与声明均出自[三星电子官方新闻稿](https://news.samsung.com/global/samsung-electronics-announces-fourth-quarter-and-fy-2025-results)（2026年1月29日发布，币种为韩元，金额单位为万亿）。

## 2025Q4实际结果

2025年第四季度（截至2025年12月31日）合并营收93.8万亿韩元，环比增长9%，创单季历史新高；营业利润20.1万亿韩元，同为历史最高。全年营收333.6万亿韩元，全年营业利润43.6万亿韩元。

## 分部数据

- **设备解决方案（DS）**：收入44.0万亿韩元，环比增长33%；营业利润16.4万亿韩元。存储业务在HBM、服务器DDR5、企业级SSD等高价值产品放量和整体价格上升带动下，季度收入与营业利润均创纪录；传统DRAM需求强劲而供应有限。System LSI业务利润下降，主因季节性需求疲弱及主要客户产品排期调整；图像传感器收入因新的200MP和50MP大像素产品而增长。Foundry收入增长，但利润改善有限，受暂定成本（provisional costs）拖累；该业务开始量产第一代2nm产品，并开始出货4nm HBM基底芯片。
- **显示面板（SDC）**：收入9.5万亿韩元，营业利润2.0万亿韩元。中小尺寸业务受主要客户智能手机需求和供应稳定推动，IT及汽车销售亦有贡献；大尺寸业务在年末旺季收入增长。
- **移动体验与网络（MX/Networks）**：收入29.3万亿韩元，营业利润1.9万亿韩元。MX业务因新品效应消退，第四季度智能手机销量下降，但2025全年实现两位数利润水平（原文未明确具体口径）。Networks业务受北美销售增长带动，环比和同比均改善。
- **消费电子（VD/DA）**：收入14.8万亿韩元，营业亏损0.6万亿韩元。VD业务靠Neo QLED/OLED和旺季需求获得收入增长，但激烈竞争压制利润；DA业务受空调淡季和全球贸易条件变化拖累。
- **Harman**：收入4.6万亿韩元，营业利润0.3万亿韩元。对欧洲OEM的车载产品供应扩大，以及新款便携/TWS音频产品发布，带动收入增长。

## 利润结构与归因

季度利润创新高主要由DS分部（尤其是存储业务）贡献；SDC与MX/Networks板块保持正利润，Harman小幅盈利，VD/DA亏损0.6万亿韩元，对整体利润拖累有限。按上述分部加总，营业利润为16.4+2.0+1.9-0.6+0.3=20.0万亿韩元，与合并营业利润20.1万亿韩元相差0.1万亿韩元，官方新闻稿未解释该差异。

## 研发投入与公司展望

第四季度研发投入10.9万亿韩元，环比增加2万亿韩元；全年研发投入37.7万亿韩元，创年度纪录。公司对2026年第一季度的指引要点包括：DS部门预期AI与服务器需求继续增长；存储业务将在该季度开始交付HBM4产品（包括11.7Gbps版本），继续扩大AI相关DDR5、SOCAMM2、GDDR7销售；Foundry收入预计因季节性环比下降，但订单预计因HPC和移动客户扩大。MX计划推出Galaxy S26系列，强化Agentic AI体验；SDC预期智能手机需求疲软，将依靠新旗舰屏幕维持销售。全年2026年目标包括Foundry实现双位数收入增长、DS引领AI时代、DX整合AI生态等，但这些都是公司目标而非实际结果。
