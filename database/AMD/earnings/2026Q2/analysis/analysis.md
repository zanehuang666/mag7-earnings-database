# AMD 2026Q2 财报后市场分析

## 一、主要结论

AMD 2026年第二季度营收创纪录，达115亿美元，同比增长50%。官方新闻稿显示，非GAAP毛利率56%、营业利润31亿美元、净利润28亿美元、摊薄每股收益1.66美元；GAAP口径每股收益1.38美元。据路透社报道，调整后每股收益1.66美元超过分析师预期的1.62美元，营收也超过11.28亿美元的预期。但路透社同时指出，AMD股价在盘后交易中下跌近9%，显示投资者在股价年内翻倍后期待更强劲的指引。

## 二、核心业务变化及其机制

数据中心是本季度核心驱动力。官方数据显示，该部门营收67亿美元，同比增长107%，占公司总营收的58%，增长来自EPYC服务器CPU和Instinct GPU需求。据路透社报道，该数字超过分析师预期的64.8亿美元，环比增长16.3%（该环比数据来自媒体测算，官方新闻稿未披露）。

产品与客户进展方面，官方新闻稿列出：Helios机架级解决方案发布，客户包括Anthropic、Meta、Microsoft、OpenAI、Oracle等；Instinct MI400系列GPU家族发布，含MI455X与MI430X；第六代EPYC服务器CPU推出；与Anthropic达成部署最高2吉瓦MI450系列GPU的战略合作。据路透社报道，苏姿丰在7月AI活动上称，搭载MI455X与台积电代工Venice处理器的第二代Helios已全面投产，将在未来数月开始出货。

其他部门：客户业务营收31亿美元，同比增长23%，受Ryzen需求推动；游戏业务营收7.79亿美元，同比下降31%，因半定制收入减少；嵌入式业务营收9.77亿美元，同比增长19%。

## 三、这些变化如何改变增长、利润、现金流的预期

官方指引显示，AMD预计2026年第三季度营收约130亿美元，上下浮动3亿美元，中值代表同比增长约41%、环比增长约13%；非GAAP毛利率预计约56%。据路透社报道，该营收指引高于LSEG汇编的分析师预期125.2亿美元，毛利率指引与预期基本一致。

据路透社报道，苏姿丰在财报电话会上表示，数据中心销售额将在2027年翻倍以上，总营收增长将超过2025年分析师日设定的35%目标，年度盈利将超过每股20美元目标。需注意，这些属于电话会上的前瞻表述，并非本次官方新闻稿的季度指引。路透社认为，这一预测表明AMD挑战英伟达AI芯片主导地位的投资开始见效。

## 四、市场如何定价

据路透社报道，尽管第三季度营收指引高于分析师预期，AMD股价仍在盘后交易中下跌近9%。Emarketer分析师Jacob Bourne对路透社表示：“AMD现在处于与英伟达和超大规模云厂商相似的位置，投资者正在寻找证据，证明AI基础设施投资将继续转化为加速的回报。”路透社指出，AMD股价年内已上涨超过一倍，AI乐观情绪推动了这一涨幅。

## 五、下一季最重要的业务验证点

第三季度最关键的业务验证点是Helios机架级解决方案的出货进展与MI400系列GPU的产能爬坡。据路透社报道，苏姿丰表示2027年机架级AI平台将整合MI500 GPU、Verano CPU和Pensando网络。此外，EPYC需求加速的持续性，以及数据中心营收能否维持环比增长以支撑2027年翻倍目标，将是市场关注焦点。
