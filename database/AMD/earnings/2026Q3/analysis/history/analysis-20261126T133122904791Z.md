# AMD 2026财年第三季度分析

**来源与口径**：本文仅依据 AMD 官方新闻稿《AMD Reports Third Quarter 2026 Financial Results》：[官方链接](https://ir.amd.com/news-events/press-releases/detail/1303/amd-reports-third-quarter-2026-financial-results)。财报于2026年11月3日发布。币种为美元。本文区分GAAP与非GAAP口径，但未获得具体差异数字，故不推算。

**核心事实**：AMD 2026财年第三季度营收为134亿美元，同比增长45%。公司称增长部分来自数据中心营收创纪录。新闻稿同时提供GAAP与非GAAP数据；除上述营收与同比增速外，本文不引用未提供指标。此处“第三季度”指2026财年第三季度，不是全年值，也不是第四季度单季值。

**解读**：45%的同比增速与“数据中心创纪录”是公司给出的主要叙事。由于缺少分部利润、毛利率、每股收益、指引等明细，无法判断增长质量、利润率和现金流影响。GAAP与非GAAP若存在差异，需以新闻稿表格和调节表为准；在未看到具体调节项前，不能把非GAAP口径当作GAAP替代。

**待核与未提供**：未提供市场共识、股价反应、分析师预期、管理层电话会细节、全年10-K数据。不得将全年值称为Q4单季值。本文没有真正的同期财报前定稿，因此明确写：无同期 Preview。若有历史重建稿，也必须标注“历史资料重建”，且只能使用上一份财报事实，不能声称为当时预测。
