# AMD 2025 财年第一季度财报后分析

**资料截止：2025-05-07 23:59:59 UTC｜数据来源：AMD 2025Q1 10-Q（SEC，2025-03-29 期末）**

## 主要结论

本季 AMD 录得收入 74.38 亿美元、经营利润 8.06 亿美元、净利润 7.09 亿美元、经营现金流 9.39 亿美元（[10-Q](https://www.sec.gov/Archives/edgar/data/2488/000000248825000047/amd-20250329.htm)）。**在缺少分部、毛利率与指引证据的前提下，可确认的判断是：公司仍处于"收入规模可观、但经营利润率偏薄"的状态**——经营利润率约 10.8%（8.06/74.38），且利润被大额非现金项目显著稀释。本季核心问题不是"赚不赚钱"，而是**利润质量与现金转化**：经营现金流（9.39 亿）高于净利润（7.09 亿），说明现金创造未被账面利润完全反映，但两者差距不大，需结合营运资本变动才能判断可持续性。

## 利润与现金

利润端的关键事实是**非现金费用对经营利润的侵蚀**：本季"其他经营损失"主要包含 **5.67 亿美元收购相关无形资产摊销**与 **3.64 亿美元股权激励费用**（[10-Q 附注](https://www.sec.gov/Archives/edgar/data/2488/000000248825000047/amd-20250329.htm)）。两项合计 9.31 亿美元，已超过当季经营利润本身——**若剔除这两项，经营利润将显著更高**，但这是非 GAAP 视角，公司未在本证据中给出调整后口径，故仅作结构性说明，不作为官方盈利数字。

现金端，经营现金流 9.39 亿美元略高于净利润 7.09 亿，差额约 2.3 亿，方向合理（摊销等非现金项回加）。但**自由现金流、资本开支、库存与应收变动均未在证据中给出**，无法判断现金转化是否健康，需查现金流量表全文。

## 本季核心问题（无同期 Preview）

本季**无同期 Preview**，故不做事后重建式预测比较。替代性地，本季应回答的核心问题是：**在分部重组与高额摊销/股权激励并存的背景下，AMD 的经营利润率能否随收入结构改善而扩张？** 现有证据只能确认利润率水平（约 10.8%），无法确认驱动因素。

## 下一季判断与关键验证点

**判断（有条件）：** 若数据中心与客户端需求延续，且摊销/股权激励绝对额不进一步扩大，经营利润率有望维持或小幅改善；但若收入环比走弱，固定性质的摊销与激励费用将放大利润率压力。

**需验证的具体项目：**
1. 各报告分部（Data Center / Client / Gaming / Embedded）收入与经营利润，确认重组后口径；
2. 毛利率及同比/环比变动；
3. 资本开支与自由现金流，判断 9.39 亿经营现金流的可持续性；
4. 管理层下季指引（收入、毛利率），本证据未包含；
5. 库存与应收账款变动，验证现金转化质量。
