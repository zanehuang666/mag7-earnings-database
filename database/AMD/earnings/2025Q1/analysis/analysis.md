# AMD 2025 自然年一季度（FY2025 Q1，截至 2025-03-29）财报后分析

**资料截止：2025-05-07 23:59 UTC**｜来源：AMD FY2025 Q1 10-Q（SEC，2025-03-29 报告期末）

## 主要结论

本季 AMD 交出一份“收入与利润率同步抬升、但结构分化明显”的季报：总收入 74.38 亿美元、同比 +36%，毛利率由 47% 升至 50%，经营利润从 0.36 亿跳升至 8.06 亿美元。核心驱动是数据中心（EPYC CPU + Instinct GPU）与客户端 Ryzen 的量价齐升，而非全产品线普涨——游戏（半定制）与嵌入式仍在拖后腿。**有条件判断**：若数据中心 GPU 与 Zen 5 客户端的量价动能延续，且游戏半定制下滑不再加速，公司盈利中枢有望维持在本季水平之上；反之，若客户端提价不可持续或数据中心费用继续膨胀，利润弹性会被侵蚀。本季无同期 Preview，故以“本季核心问题”替代复核。

## 财报数据与主要产品

- 总收入 **74.38 亿美元**，同比 +36%（[10-Q](https://www.sec.gov/Archives/edgar/data/2488/000000248825000047/amd-20250329.htm)）。
- **数据中心**：收入 37 亿美元，同比 +57%，经营利润 9.32 亿（上年同期 5.41 亿），由 EPYC CPU 与 Instinct GPU 销售增长驱动。
- **客户端与游戏**（本季起合并为一个报告分部）：收入 29 亿美元，同比 +28%。其中客户端 23 亿、同比 +68%，均价 +43%、出货量 +23%；游戏 6.47 亿、同比 -30%，主因半定制收入下降。
- **嵌入式**：收入 8.23 亿美元，同比 -3%，终端需求“mixed”。
- 国际销售占比 66%（上年同期 60%）。

## 利润与现金

毛利率 **50%**（上年 47%），公司归因于数据中心收入占比提升与 Ryzen 产品结构改善。经营利润 8.06 亿、净利润 7.09 亿，增幅远高于收入，除毛利改善外还得益于**收购相关无形资产摊销减少**，部分被经营费用上升抵消——营销及行政费用 8.86 亿、同比 +46%，主要投向客户端与游戏的 go-to-market。经营现金流 **9.39 亿美元**，为正但明显低于净利润，需在后续核对营运资本与库存变动细节。重组方面，2024 计划本季无新增费用，支付遣散费 0.75 亿，期末负债降至 0.14 亿，基本收尾。

## 本季核心问题（无同期 Preview）

1. **增长是否集中于 AI/数据中心？** 是——数据中心贡献了主要增量，且经营利润率最高。
2. **客户端提价能否持续？** 均价 +43% 是本季利润弹性的关键，但公司自陈面临 Intel 激进定价与 Nvidia 生态锁定，属需持续验证项。
3. **游戏与嵌入式拖累是否见底？** 证据不足，尚待核实。

## 下一季判断与关键验证点

- 验证数据中心 GPU（Instinct）出货与客户结构，确认增长非一次性。
- 跟踪客户端均价与出货量能否同时维持，警惕提价见顶。
- 观察游戏半定制收入降幅是否收窄、嵌入式库存去化进度。
- 核对经营现金流与净利润缺口、资本开支及库存变化。
- 关注合并分部后披露口径变化对可比性的影响。
