# NVIDIA 2026Q4（FY2027 Q3）财报分析

财季于2026年10月25日结束，对应自然季度2026Q4。本稿仅依据 NVIDIA 官方新闻稿，不引用市场共识或公司后续披露。

## 实际结果
- 总营收：1158 亿美元，同比增长 103%。
- GAAP 毛利率：74.8%。
- GAAP 摊薄每股收益：2.70 美元。
- Data Center 营收：1076 亿美元。
