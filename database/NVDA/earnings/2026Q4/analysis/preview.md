# 历史资料重建：NVIDIA FY2027 Q3财报前瞻

> 本文是事后重建：仅使用NVIDIA于2026年8月26日发布的FY2027 Q2财报新闻稿。截至资料截止日，本文未使用该季度财报公布后的任何信息，也不应被理解为财报前实时预测。

**上季基准（FY2027 Q2，截至2026年7月26日）**
- 营收$96.2B，环比+18%、同比+106%；GAAP与非GAAP毛利率均为75.0%；GAAP摊薄EPS $2.46，non-GAAP $2.22。
- 数据中心营收$89.0B，环比+18%、同比+117%；边缘计算$7.2B，环比+13%、同比+27%。[（来源：Q2 FY2027新闻稿）](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027/)
- 当季向股东返还约$26.0B；剩余回购授权约$99.0B；季度股息$0.25/股。自FY2027 Q1起，non-GAAP不再剔除股权激励费用。

**公司对FY2027 Q3的指引**
- 营收$108.0B±2%，指引未计入来自中国的任何数据中心计算收入。
- GAAP与非GAAP毛利率均为74.0%±50bp；GAAP营业费用约$9.2B，non-GAAP约$9.0B。
- FY2027全年GAAP与非GAAP税率预计16%–18%，不含离散项目。

**本季三个核心问题**
1. 中国收入假设：若实际出现中国数据中心计算收入，指引是否偏保守？若仍为零，其他地区是否补足缺口？
2. 毛利率指引环比下降1个百分点，是否反映Vera Rubin量产初期组合变化？新闻稿称Vera Rubin已进入全面生产。
3. 边缘计算能否延续环比+13%：PC/工作站、汽车/机器人、主权AI是观察点。

**正负预期差**
- 正面：指引中点隐含环比约+12%；CEO称需求加速、前沿实验室并行扩张、AI基础设施“全速建设”；Apollo等合作拟动员超$5,000亿第三方资金，尚需最终协议。
- 负面：中国数据中心收入被剔除；毛利率回落；营业费用环比增约$0.8B；$5,000亿为长期、以最终协议为准，不构成当期订单。

**财报验证点**
- 营收落在$105.8B–$110.2B；毛利率落在74.0%±50bp；营业费用是否约$9.2B/$9.0B。
- 数据中心与边缘计算分部收入；中国数据中心计算收入的实际披露口径。
- 资本返还/回购执行；税率是否处于16%–18%。
- 新闻稿未披露市场一致预期，故本稿不使用共识数字。
