# NVIDIA FY2025 10-K 分析（日历 2025Q1 披露）

**范围与口径**：本文只依据所给官方 10-K。文件覆盖 2024-01-29 至 2025-01-26，数字为美国 GAAP 全年值，不是 Q4 单季值。来源复核待核。

**核心数字（全年）**
- 收入：130,497,000,000 美元（Revenues）。
- 营业利润：81,453,000,000 美元（OperatingIncomeLoss）。
- 净利润：72,880,000,000 美元（NetIncomeLoss）。
- 经营现金流：64,089,000,000 美元（NetCashProvidedByUsedInOperatingActivities）。

**分析**：按全年口径，公司录得大额收入、营业利润、净利润和正经营现金流。但这只能说明全年总量，不能推导 Q4 单季表现、季度环比或同比增速，因为来源未提供单季拆分。本文不补造共识、股价反应或未提供数字。若按日历2025Q1节点讨论，也必须区分“披露时点”与“财务期间”。本稿无真正的财报前定稿，因此明确写明：无同期 Preview。若另见历史重建稿，标题应标明“历史资料重建”，且只使用上一份财报事实，不能当成当时预测。

**限制**：只有年度合并数据，缺少分部、地区、产品线、季度与同比对比；不对未提供项作推断。所有金额均为美元。
