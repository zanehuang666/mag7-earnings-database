# NVDA 2025Q4 分析（口径待核）

本文标题沿用任务中的 NVDA 2025Q4，但所给官方来源的 XBRL 事实只覆盖 **2025-07-28 至 2025-10-26** 的单季期间。因此正文按单季口径处理，不把该期间直接认定为某一个正式财季。

该期间内：

- 营收：**570.06 亿美元**（US GAAP，标签 Revenues）
- 营业利润：**360.10 亿美元**（US GAAP，标签 OperatingIncomeLoss）
- 净利润：**319.10 亿美元**（US GAAP，标签 NetIncomeLoss）

来源：[NVIDIA SEC filing, nvda-20251026.htm](https://www.sec.gov/Archives/edgar/data/1045810/000104581025000230/nvda-20251026.htm)。

需要强调：这些数字是季度值，不是 10-K 全年值；不能把全年值称为 Q4 单季值，也不能反过来把单季值当成全年。币种为美元，准则为 US GAAP，数据由 SEC XBRL 提取。来源复核状态标注为 pending，因此财季命名、同比/环比基础、以及是否可将该期间称为 2025Q4 均待核。

本文没有可用的同期 Preview，也没有真正的财报前定稿，因此不把任何历史重建稿当成同期预测。若未来出现历史资料重建，必须在标题标明“历史资料重建”，且只能使用上一份财报的事实，不能声称为当时发表的预测。当前分析不补造共识预期、股价反应或未提供的数字。

在缺乏对比期时，单季绝对额只能说明该期间规模，不能单独判断增长、利润率或趋势。阅读时应先核对财季定义，再决定是否使用这些数字做跨期比较。
