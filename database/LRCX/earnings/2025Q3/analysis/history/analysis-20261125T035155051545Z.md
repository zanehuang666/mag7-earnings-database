# 泛林集团（LRCX）2025 财年第三季度财报后分析

**资料截止：2025-10-24 23:59:59 UTC｜数据来源：SEC 10-Q（accession 0000707549-25-000085）**

## 主要结论

本季（2025-06-30 至 2025-09-28）泛林交出一份"收入稳、毛利改善、现金强劲"的季度：营收 53.24 亿美元，营业利润 18.29 亿美元，净利润 15.69 亿美元，经营现金流 17.79 亿美元。毛利率升至 50.4%，公司归因于客户结构改善，但被工厂效率下降、关税相关支出和材料成本上升部分抵消。**有条件判断**：本季利润质量尚可（毛利改善来自结构而非一次性项目），但收入增长的主要驱动是成熟制程代工设备支出，而非存储——存储（尤其非易失性存储）环比走弱。这意味着增长的可持续性取决于代工资本开支节奏，而非行业全面复苏。现金转化良好，但需注意递延收入环比下降对后续确认节奏的影响。

## 财报数据与主要产品

- 营收：**53.24 亿美元**（2025-06-30 至 2025-09-28，US GAAP）。[来源](https://www.sec.gov/Archives/edgar/data/707549/000070754925000085/lrcx-20250928.htm)
- 营业利润：**18.29 亿美元**；净利润：**15.69 亿美元**（同上期间）。
- 收入结构：系统收入（沉积、刻蚀、清洗等新设备）与客户支持相关收入（服务、备件、升级及 Reliant 非领先设备）两大类。客户支持相关收入本季为 **17.77 亿美元**，与上年同期 17.75 亿美元基本持平，说明本季同比增长主要来自系统设备而非服务。
- 终端市场：代工环比走强，由**成熟节点投资**驱动；存储环比下降，主因非易失性存储减少。逻辑/IDM 占比由上年同期 24% 降至 6%（领先/非领先设备及升级口径），结构变化显著。

## 利润与现金

毛利率 **50.4%**，高于 6 月季度的 50.1% 和上年同期的 48.0%。公司明确：环比改善来自客户结构，被工厂效率下降、关税支出和材料成本上升部分抵消；同比改善主要来自客户结构。研发费用率 10.8%（6 月季度 11.2%、上年同期 11.9%），SG&A 费用率 5.2%，费用端相对克制。

经营现金流 **17.79 亿美元**，资本开支及无形资产 **1.85 亿美元**（上年同期 1.11 亿美元），自由现金流仍充裕。递延收入方面：6 月末 26.81 亿美元递延收入中，本季确认 **9.966 亿美元**（占 37%）；9 月末递延收入降至 **21.87 亿美元**（流动部分），另有非流动 5.15 亿美元等。递延收入环比下降，需关注其对未来季度收入确认的支撑力度。

## 本季核心问题（无同期 Preview）

本季无同期 Preview，故不做事后重建式比较。本季应回答的核心问题是：**在存储走弱背景下，代工成熟节点需求能否持续支撑收入，以及毛利改善是否可持续？** 实际结果给出部分正面答案——收入与毛利均环比改善，且改善来自客户结构而非一次性收益；但存储疲软和递延收入下降构成隐忧。

## 下一季判断与关键验证点

**判断**：若成熟节点代工投资延续，收入有望维持当前水平；但存储（非易失性）若继续走弱，可能拖累系统收入。毛利能否守住 50% 以上，取决于客户结构与关税/材料成本走向。

**关键验证点**：
1. 下一季代工与存储收入占比变化，尤其非易失性存储是否止跌；
2. 递延收入余额及确认节奏，是否继续环比下降；
3. 毛利率是否维持 50% 以上，关税与材料成本影响是否扩大；
4. 资本开支与经营现金流匹配度；
5. 客户支持相关收入能否恢复增长（本季同比几乎零增长）。

**尚待核实**：分部/产品线明细、资本开支指引、管理层业绩指引、市场共识及股价反应，本次证据未提供，需查后续 8-K 或财报电话会记录。
