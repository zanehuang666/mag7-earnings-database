# LRCX 2026 财年（截至 2026-06-28）财报后分析

**资料截止：2026-08-07 23:59:59 UTC｜来源：SEC 10-K（accession 0000707549-26-000037）**

## 主要结论

本次证据只覆盖**2026 财年全年**（2025-06-30 至 2026-06-28），**没有 Q4 单季数据，也没有同期 Preview**，因此无法做单季预测复核。就全年而言，判断是：**收入与毛利率同步扩张，增长由代工（foundry）设备支出驱动，而非存储；利润与经营现金流均创强，但现金转化率明显低于净利润，且递延收入下降，需在下一季验证订单动能是否延续。**

## 财报数据与主要产品

全年收入 **232.33 亿美元**（[10-K](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)），营业利润 **82.00 亿美元**，净利润 **72.65 亿美元**。公司仅有一个报告分部（晶圆加工设备制造与服务），产品分两类：

- **系统收入**：全年同比增加 **33.9 亿美元（+29.5%）**，主因是**代工客户设备支出**。
- **客户支持相关及其他收入**：全年同比增加 **14.0 亿美元（+20.2%）**，主因是备件与非领先制程设备（Reliant 产品线）。

终端市场结构变化明显：**代工占比全年提升 900 个基点**（成熟节点支出 + 领先制程投资）；**存储占比下降 300 个基点**，公司归因于客户投资时点。逻辑/IDM 占比从 13% 降至 7%。这说明本轮增长是**代工驱动、存储偏弱**的结构，与"存储周期复苏"叙事不同。

## 利润与现金

毛利率 **50.5%**，同比提升 **180 个基点**，公司归因于**有利的客户结构**，部分被铝、钢关税相关支出抵消。费用端：研发占收入比从 11.4% 降至 **10.2%**（绝对额仍增，含 1.314 亿美元人员成本、6980 万美元工程耗材）；SG&A 占比从 5.3% 降至 **4.9%**（人员成本增 1.80 亿美元）。**毛利率扩张 + 费用率摊薄**是营业利润率改善的双引擎。

现金流方面，全年经营现金流 **58.58 亿美元**，对净利润 72.65 亿美元的转化率约 **81%**，存在缺口。资本开支及无形资产 **9.66 亿美元**（上年 7.59 亿），自由现金流约 **48.9 亿美元**（经营现金流减资本开支，属推算）。**递延收入从 26.8 亿美元降至 24.3 亿美元**，公司归因于客户预付款减少、部分被已赚取系统信用抵消——这是需要警惕的前瞻信号。

## Preview 判断复核

**无同期 Preview**，故不做预测偏差比较。本季（本财年）核心问题应改写为：**代工驱动的增长能否在存储未同步复苏的情况下延续，以及递延收入下降是否预示订单放缓？**

## 下一季判断与关键验证点

**判断（有条件）**：若代工领先制程与成熟节点支出维持，收入与毛利率有望保持强势；但递延收入下滑与存储占比走弱构成下行风险，**不宜线性外推全年增速**。

关键验证点（均需查下一份 10-Q/财报）：
1. **Q4/下一季单季收入、毛利率**——本次仅有全年，无法判断季度动能。
2. **递延收入是否继续下降**，及客户预付款趋势。
3. **存储占比是否回升**，代工占比能否守住。
4. **经营现金流对净利润转化率**是否修复。
5. **关税对毛利率的拖累幅度**是否扩大。
6. 公司**下一季指引与市场共识**——本次证据未提供，尚待核实。
