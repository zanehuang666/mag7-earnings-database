# LRCX FY2026 10-K 速览：不是2026Q2单季

> 来源：[SEC 10-K](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)。数据为 **US GAAP、USD、2025-06-30 至 2026-06-28 全年**，不是Q4或2026Q2单季。Lam财年于6月底结束；若2026Q2指财年第二季度，本来源未给单季值。**无同期 Preview**。

## 全年损益
- 营收 **23,232,690,000 美元**。
- 营业利润 **8,199,795,000 美元**；据此全年营业利润率约 **35.3%**。
- 净利润 **7,265,396,000 美元**；据此全年净利润率约 **31.3%**。

## 全年现金流
- 经营活动现金流 **5,857,657,000 美元**，约相当于全年营收的 **25.2%**。
- 经营现金流低于净利润，可能受营运资本、非现金项目或税款支付时点影响；10-K附注细节未在给定事实中展开，**待核**。
