# 历史资料重建：LRCX [2026Q3](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm) 财报前瞻

所给官方文件仅覆盖截至 [2026-06-28](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm) 的完整财年，并非单季；因此以下为事后重建的前瞻观察。上期财务总量为：营收 [USD 23,232,690,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)，营业利润 [USD 8,199,795,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)，净利润 [USD 7,265,396,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)，经营现金流 [USD 5,857,657,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)。四项均为正，说明全年盈利与现金创造仍具规模；但经营现金流低于净利润，需留意回款与营运资本。来源未提供业务分部细节，故不展开产品线判断。

本季两个验证问题：
- 收入验证：在全年营收 [USD 23,232,690,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm) 的基数下，单季收入能否体现客户资本开支和验收节奏，而非仅受确认时点影响？
- 利润与现金验证：全年营业利润 [USD 8,199,795,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm)、净利润 [USD 7,265,396,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm) 和经营现金流 [USD 5,857,657,000](https://www.sec.gov/Archives/edgar/data/707549/000070754926000037/lrcx-20260628.htm) 的组合，能否在单季保持利润与现金流同步，而非继续背离？

正负情形：
- 正面：若需求、交付与回款节奏稳定，单季收入、营业利润、净利润与经营现金流可延续四项为正的态势。
- 负面：若客户推迟验收或营运资本占用上升，单季收入承压，利润率与经营现金流可能弱于全年平均，净利润也可能受非经营项目扰动。

不写本季实际结果，不编造共识或股价。
