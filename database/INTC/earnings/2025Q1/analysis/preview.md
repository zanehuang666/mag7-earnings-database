# 历史资料重建：INTC 2025Q1 财报前瞻

> 说明：本文仅据截至2025-01-31已公开的上一份SEC申报重建，非当时预测，也不包含2025Q1实际结果。

## 上一财年概览
最新申报覆盖2023-12-31至2024-12-28完整财年，而非单季。按US GAAP，收入为[531.01亿美元](https://www.sec.gov/Archives/edgar/data/50863/000005086325000009/intc-20241228.htm)；经营亏损为[116.78亿美元](https://www.sec.gov/Archives/edgar/data/50863/000005086325000009/intc-20241228.htm)；净亏损为[187.56亿美元](https://www.sec.gov/Archives/edgar/data/50863/000005086325000009/intc-20241228.htm)；经营活动现金流为[82.88亿美元](https://www.sec.gov/Archives/edgar/data/50863/000005086325000009/intc-20241228.htm)。收入规模仍大，但利润端显著承压，亏损可能与减值、重组等非经常因素相关；现金流为正，说明经营层面仍有现金生成能力，但需观察其与资本开支的匹配。

## 本季两个验证问题
1. **盈利修复**：产品与代工业务能否推动毛利率回升，使经营亏损环比收窄？关键看收入结构、产能利用率和费用控制。
2. **现金与投入**：经营活动现金流能否继续为正，并覆盖资本开支？关键看营运资本变化与代工扩张节奏。

## 正负情形
**正面情形**：若收入企稳、成本削减见效、非经常损失不再扩大，经营亏损可能收窄，现金流保持正数，并缓解资产负债表压力。  
**负面情形**：若需求疲弱、价格竞争或产能利用率低下，毛利率可能继续承压，亏损扩大；若资本开支高企而经营现金流走弱，现金消耗将更受关注。
