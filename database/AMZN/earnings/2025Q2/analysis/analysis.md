# 亚马逊 2025Q2 财报后分析

**资料截止：2025-08-01 23:59:59Z｜数据来源：SEC 10-Q（截至 2025-06-30 季度）**

## 主要结论

本季亚马逊呈现"收入体量庞大、经营利润率稳健、现金创造强劲"的组合：单季收入 1,677.02 亿美元，经营利润 191.71 亿美元，对应经营利润率约 11.4%；净利润 181.64 亿美元，高于经营利润，说明非经营项目（含权益投资等）对净利形成正向贡献。单季经营现金流 325.15 亿美元，现金转化质量良好。**有条件判断**：若下半年 AWS 与广告维持增长、且资本开支节奏不失控，当前利润率与现金流水平具备延续性；反之，若履约与 AI 基础设施投入加速，折旧与租赁成本将滞后侵蚀利润率。需注意：本季无同期 Preview，故下文以"本季核心问题"替代预测复核。

## 利润与现金

经营利润率约 11.4%（191.71 / 1,677.02），净利润高于经营利润，差额主要来自非经营收益——原文现金流量表片段显示"Total non-operating income (expense)"存在多期数值（573、1,686、-1,751、4,960，单位百万美元），但期间归属无法从节选中确认，故不引用为 Q2 单季数。**推论**：净利超经营利润通常源于利息收入、权益证券公允价值变动等，属非经营性、波动性较大，不宜线性外推。

现金端，单季经营现金流 325.15 亿美元，显著高于净利润，反映折旧摊销等非现金项回加。原文提及融资活动现金流为负（-214.40 亿与 -86.52 亿两组数值，期间待核），并披露 2025-06-30 现金及等价物与受限现金合计 823.12 亿美元（对比 614.53 亿美元，期间需核对）。**尚待核实**：自由现金流、资本开支、设备采购现金支出未在证据中明确，需查现金流量表投资活动部分。

## 本季核心问题（无同期 Preview）

因无同期 Preview，无法逐项比较预测偏差。本季应回答的核心问题是：**在收入规模创新高的同时，利润率与现金流能否同步走强？** 从数据看，11.4% 的经营利润率与 325 亿美元经营现金流给出肯定信号，但利润结构对非经营收益的依赖、以及分部盈利质量仍不透明，是判断持续性的关键缺口。

## 下一季判断与关键验证点

**判断**：若 AWS 与广告保持双位数增长、履约效率不倒退，Q3 经营利润率有望维持当前区间；但若 AI 数据中心与物流资本开支提速，折旧与融资租赁成本将滞后压制利润率。

**关键验证点**：
1. 10-Q 分部附注：AWS、北美、国际收入与经营利润，确认利润来源；
2. 资本开支与自由现金流：投资活动现金流出、设备采购规模；
3. 非经营收益构成：净利超经营利润的可持续性；
4. 租赁与折旧：原文显示融资租赁资产与累计摊销规模庞大，需跟踪其对未来利润的摊销压力；
5. 汇率影响：原文提供汇率对净销售、经营费用的影响表，需核对 Q2 实际汇兑拖累。
