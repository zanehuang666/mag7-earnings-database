# AMZN 2026Q3 财报后市场分析

## ①主要结论

亚马逊 2026 财年第三季度业绩呈现“运营强劲但盈利略逊”的分化格局。据公司财报，净销售额为 2019 亿美元，营业利润 281 亿美元，营业利润率 13.9% 创历史新高。但据 Investing.com 的财报电话会记录，每股收益 1.89 美元，低于市场预期的 1.96 美元，营收也略低于预期约 2 亿美元。路透社标题称“AI 支出盖过五年来最快云增长”，美联社标题则称“季报令人失望但云增长强劲”。据 Investing.com 解读，市场焦点从强劲的底层增长转向了盈利不及预期和巨额资本开支。

## ②核心业务变化及其机制

AWS 仍是最大增长引擎。据公司财报，AWS 收入 460 亿美元，同比增长 39.3%。据 Investing.com 报道，AWS 营业利润 178 亿美元，利润率 38.7%；广告业务收入 196 亿美元，同比增长 12%；北美收入 1129 亿美元，增长 6%，营业利润率 7.7%；国际收入 431 亿美元，剔除汇率影响增长 8%。公司称，通过机器人技术、库存优化和配送网络调整，零售成本持续下降。据 Investing.com 报道，季度资本开支高达 759 亿美元，主要用于 AI 和云基础设施；管理层在财报电话会上表示，AWS 在 2027 和 2028 年可保持 40% 以上增速。

## ③这些变化如何改变增长、利润、现金流的预期

AWS 的加速增长和创纪录的营业利润率强化了长期盈利前景，但每股收益不及预期和巨额资本开支引发了对近期自由现金流的担忧。据 Investing.com 的财报电话会记录，市场更关注盈利不及预期和支出规模，而非强劲的底层增长。据 Investing.com 报道，管理层对 AWS 未来两年 40% 以上增速的指引，意味着云业务将继续贡献高利润，但资本开支的持续攀升可能在短期内压制每股收益和自由现金流。零售利润率改善和广告增长则提供了一定的利润缓冲。

## ④市场如何定价，说明股价反应和具名机构分歧

市场反应剧烈。据 Investing.com，亚马逊股价在常规交易时段下跌 4.25% 至 243.79 美元，盘后再跌 6.11% 至 228.9 美元，较前收盘累计下跌约 10.1%。路透社标题强调“AI 支出盖过五年来最快云增长”，美联社标题则称“季报令人失望但云增长强劲”，显示媒体对同一份财报的解读存在分歧。据 Investing.com 报道，每股收益 1.89 美元低于预期的 1.96 美元，营收略低于 2021 亿美元预期。市场定价明显偏向短期盈利压力和支出担忧，而非长期增长潜力。

## ⑤下一季最重要的业务验证点

第四季度最重要的验证点是 AWS 增速能否维持接近 40% 的水平，以及资本开支对利润率的实际影响。公司对第四季度销售的谨慎展望需要观察实际落地情况。广告业务能否保持双位数增长、零售利润率改善是否持续，也将影响市场对盈利能力的信心。此外，据 Investing.com 报道，管理层关于 2027-2028 年 AWS 增速的指引是否获得更多订单或产能数据支撑，将是判断当前支出周期回报的关键。
