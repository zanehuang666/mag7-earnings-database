# AMZN 2025 年第一季度分析

来源：[SEC 申报文件](https://www.sec.gov/Archives/edgar/data/1018724/000101872425000036/amzn-20250331.htm)。数据口径：US GAAP。期间：2025-01-01 至 2025-03-31。币种：美元。本文无同期 Preview；截至资料时点，未取得当时发布的财报前定稿，因此不做“预期对实际”比较。来源审查待核。

## 核心数据
该季度营收为 1556.67 亿美元。该季度营业利润为 184.05 亿美元。该季度净利润为 171.27 亿美元。该季度经营活动现金流为 170.15 亿美元。上述四项均为季度值，不是 10-K 全年值，也不是第四季度单季值。链接同上。

## 解读
营收与营业利润同处一个季度，表明核心经营在 2025Q1 录得正营业利润。净利润比营业利润低 12.78 亿美元；差异来自营业外、税务等项目，净影响为负，但申报摘要未展开构成，故不归因。经营现金流为 170.15 亿美元，与净利润 171.27 亿美元接近；两者口径不同，不能直接等同。季度现金流受营运资本时点影响，单季数值不宜外推全年。缺少同期 Preview，无法计算“超预期/低预期”。缺少分部、AWS、广告、Prime 等明细，无法判断增长驱动。缺少电话会、指引与股价反应资料，不评价市场反应。
