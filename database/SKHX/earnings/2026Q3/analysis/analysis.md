# SKHX 2026Q3 财报分析

> 来源：[SK hynix 3Q26 业绩新闻稿](https://news.skhynix.com/en/q3-2026-business-results/)（2026-10-28，K-IFRS合并初步数据）

## 复核基准

无同期 Preview。来源库未提供财报前定稿文章，本次 Analysis 不做“预期 vs 实际”的逐项复核；也不引用任何市场共识数字。公司声明本业绩为初步数据，可能随审计调整。

## 实际结果

- **收入**：104.6155万亿韩元，环比+32%，为公司历史上首次单季突破100万亿韩元；同比+328%。
- **营业利润**：83.3338万亿韩元，环比+38%，营业利润率80%（2Q26为76%）。
- **净利润**：39.7756万亿韩元，净利率38%，环比-58%（2Q26为93.9226万亿韩元）。新闻稿未解释净利润环比下降的原因；营业利润创新高表明净利润下降不宜直接解读为经营恶化，需待完整报表确认非营业损益与税务影响。

## 业务与利润来源

收入增长由高附加值产品带动：服务器DDR5销售明显增加；HBM4出货开始放量；NAND方面321层TLC eSSD销售扩大。公司称AI内存需求推动主要产品价格上升。

## 现金与资产负债表

季末现金及现金等价物114.5万亿韩元，环比增加26.5万亿韩元；借款环比减少2.8万亿韩元至15.8万亿韩元；净现金98.7万亿韩元。

## 公司指引与股东回报

- HBM4预计在第四季度出货量和收入均超过HBM3E，成为主流产品；这是公司指引，不是已实现结果。
- 已与14家主要客户签署长期协议，覆盖2027–2028年产能的50%以上；合同期通常为五年，并设有反映市场条件的价格区间。
- 公司预计供应短缺持续至2030年，明年投资将显著增加，Yongin一期进入全面运营。
- 2026财年股东回报计划总额约100万亿韩元：现金股息30万亿韩元以上、回购注销60万亿韩元以上（含8月公布的40万亿韩元）。8月公布的回购已完成；3Q26董事会决议派发季度现金股息14万亿韩元（每股2万韩元，其中1万韩元为Kioxia投资特别股息）及20万亿韩元回购，其中10万亿韩元计入股东回报并注销，另约10万亿韩元用于员工薪酬。
- CEO宣布停止评估Solidigm IPO，理由是当前金融市场条件下无法实现原定目标。

## 下一季要点

1. HBM4是否按指引在第四季度超过HBM3E，成为出货量与收入主流。
2. 321层NAND占国内产能是否超过一半，以及高价值eSSD的销售占比。
3. 2027年投资规模与长期协议的新增覆盖范围。
4. 股东回报执行节奏，以及Kioxia投资收益的会计确认。
5. 最终审计报表能否解释净利润环比下降的原因。
