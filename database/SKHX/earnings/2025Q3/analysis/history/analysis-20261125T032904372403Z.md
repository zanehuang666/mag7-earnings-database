# SKHX（SK hynix）2025Q3 财报分析

## 核心数字
据SK hynix官方IR，2025Q3按K-IFRS口径：营收 KRW 24.4489万亿；营业利润 KRW 11.3834万亿；净利润 KRW 12.5975万亿。三项均为该季度值，币种为韩元，非全年或单月值。来源：[SK hynix 2025Q3官方发布](https://news.skhynix.com/en/sk-hynix-announces-3q25-financial-results/)。

## 盈利能力
同一来源披露营业利润率为47%。该数字按字面对应营业利润/营收，不宜外推为净利润率。官方称本季为创纪录表现，并提到12-high HBM3E与服务器DDR5支撑。至于“创纪录”是否指历史最高，来源未给对比序列，待核。

## 驱动与限制
官方将表现与12-high HBM3E、服务器DDR5相联。除这些公司口径外，本文不补充出货量、ASP、客户结构、资本开支或分部利润，因为所给来源未提供，标为待核。
