# 希捷科技（STX）FY2026 全年业绩后分析

**资料截止：2026-08-04 23:59:59 UTC｜来源：SEC 10-K（accession 0001137789-26-000159）**

## 主要结论

本季（FY2026 第四财季）**没有可用的单季数据**，官方文件提供的是截至 2026-07-03 的**全年**口径。因此本文的判断限定在全年层面：希捷 FY2026 收入约 122 亿美元、营业利润约 41 亿美元、净利润约 32 亿美元，净利率 27%（上年 16%），毛利率 46%（上年 35%）。**核心变化是"量价齐升 + 产品结构上移"共同推动的盈利跃升**，而非单纯成本削减。但单季收入、单季利润率、指引、共识与市场反应均尚待核实，不能由全年数字倒推。

## 财报数据与主要产品

- **收入**：全年 USD 12,195 百万，同比增约 34%（约 +31 亿美元）。公司明确归因于**近线（nearline）exabytes 出货增加**，反映近线需求上升，以及公司主动的**定价行动**。
- **营业利润**：全年 USD 4,094 百万。
- **净利润**：全年 USD 3,184 百万，占收入 27%（上年 16%）。
- **毛利率**：全年 46%，同比提升 11 个百分点，公司归因于定价行动与**向高容量产品的结构转移**。
- **产品线索**：文件提及 consolidated revenues 按渠道、地域、市场及 **HDD exabytes shipped** 拆分，但具体分部/产品数字未在证据中给出，尚待核实。

## 利润与现金

利润端的传导链条清晰：**近线需求 → 出货量增 → 定价改善 + 高容量占比提升 → 毛利率 +11pct → 净利率 +11pct**。这是经营事实（公司原文归因），但"定价行动"的可持续性属推论，需后续季度验证。

现金端：全年**经营活动现金流 USD 3,674 百万**，低于净利润 3,184 百万之上的现金转化预期需谨慎——两者口径不同，不能直接比较。期末现金及等价物加受限现金 USD 1,705 百万（上年 893 百万）。值得注意的两点：

1. **应收账款保理**：FY2026 **未**出售任何应收账款；FY2025 曾无追索出售 692 百万美元。这意味着 FY2026 经营现金流未依赖保理"美化"，质量相对更实。
2. **供应链金融（SCF）**：相关负债计入应付账款，付款计入经营现金流。SCF 余额明细在证据中被截断，**具体金额尚待核实**——这是评估经营现金流质量的关键项目。

## Preview 判断复核

**无同期 Preview**（preview_status: no contemporaneous preview），故不作逐项预测对比。改写为**本季核心问题**：全年 34% 收入增长与 11pct 毛利率提升，有多少来自可持续的定价/结构，多少来自周期性近线需求？单季是否延续了这一趋势？——现有证据无法回答，需 Q4 单季数据。

## 下一季判断与关键验证点

**有条件判断**：若近线需求与定价行动延续，FY2027 开局利润率有望维持高位；但全年高基数（收入 +34%、毛利率 46%）使同比进一步扩张的难度上升，一旦定价松动或产品结构回摆，毛利率回落会直接放大到净利。

**需查的具体项目**：
1. Q4 单季收入、毛利率、净利率（区分于全年值）；
2. 近线 exabytes 出货与 HDD 分部/产品收入拆分；
3. SCF 期末余额及应付账款账龄；
4. 资本开支与折旧（全年折旧 268 百万，上年 251 百万）；
5. FY2027 官方指引与市场共识；
6. 财报后股价反应。
