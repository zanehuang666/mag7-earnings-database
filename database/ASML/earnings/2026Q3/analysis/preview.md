# 历史资料重建：ASML 第三季度财报前瞻

上季 ASML 营收 [9.326 亿欧元](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results)，毛利率 [54.0%](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results)，净利润 [2.918 亿欧元](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results)。其中安装基础管理销售额 [2.762 亿欧元](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results)，显示存量装机与服务业务仍提供利润缓冲。公司对本季营收指引为 [110 亿至 120 亿欧元](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results)，隐含环比显著回升，市场关注其能否由 EUV 与 High-NA 交付、以及逻辑与存储客户资本开支修复驱动。

本季两个验证问题：其一，营收能否落在 [110 亿至 120 亿欧元](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results) 指引区间，且毛利率能否守住上季 [54.0%](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results) 附近？其二，安装基础管理收入能否延续上季 [2.762 亿欧元](https://investor.asml.com/news-releases/news-release-details/q2-2026-financial-results) 的韧性，并抵消设备交付确认节奏波动？

正向情形：订单与交付顺利，营收靠近指引上沿，毛利率改善，净利润弹性高于营收。负向情形：客户验收延后或产品组合不利，营收处指引下沿，毛利率承压，净利润增速低于营收。以上仅为前瞻框架，不构成实际结果、共识或股价预测。
