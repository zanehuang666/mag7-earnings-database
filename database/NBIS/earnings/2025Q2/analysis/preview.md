# 历史资料重建：NBIS [2025Q2](https://nebius.com/newsroom/nebius-group-n-v-announces-first-quarter-2025-financial-results) 财报前瞻

上季，Nebius Group 公布集团收入 [55.3 百万美元](https://nebius.com/newsroom/nebius-group-n-v-announces-first-quarter-2025-financial-results)，同比增长 [385%](https://nebius.com/newsroom/nebius-group-n-v-announces-first-quarter-2025-financial-results)，并明确为管理层公布的未经审计季度结果。该新闻稿在本次给定事实中未提供利润、净利润或每股收益细节，因此本前瞻不对利润数字作推测，只基于收入增长与披露口径展开。业务层面，核心看点是收入高增是否由 AI 基础设施需求与客户上量驱动，以及未经审计结果是否在后续报告中被平稳确认。

本季前瞻提出以下验证问题：

- 验证问题A：收入高增能否延续？上季同比增长 [385%](https://nebius.com/newsroom/nebius-group-n-v-announces-first-quarter-2025-financial-results)，若本季新客户签约、算力上线和既有合同消耗继续推进，收入动能可保持；若需求递延、交付延迟或客户集中度风险显现，增速可能承压。
- 验证问题B：未经审计口径会否带来调整？上季结果属未经审计，若本季正式披露无重大修正，且成本与折旧节奏可控，利润可见度将改善；若出现审计调整、成本上升或利用率不足，利润端可能弱于收入表现。
