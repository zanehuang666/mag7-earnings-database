# 历史资料重建：META [2025Q1](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm) 财报前瞻

上一份官方披露覆盖截至 [2024年12月31日](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm) 财年（全年，并非Q4单季）。META全年营收 [1645.01亿美元](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm)，营业利润 [693.80亿美元](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm)，净利润 [623.60亿美元](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm)，经营现金流 [913.28亿美元](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm)。这显示其广告与现金生成能力仍强，利润规模高；但全年数据不宜直接外推至单季。

## 本季验证问题
- 广告收入韧性：收入能否延续全年体现的变现能力，同时消化汇率、监管与流量结构变化？
- 利润与现金流纪律：AI、基础设施与元宇宙投入是否再度抬升成本，从而影响营业利润与经营现金流？

## 正负情形
- 正面情形：若广告需求稳定、推荐与短视频变现效率提升，收入与利润端可能保持规模效应；经营现金流也可能延续全年健康水平。
- 负面情形：若投入加速、宏观或监管逆风增强，营业利润率与经营现金流可能承压，收入增速亦可能放缓。

本前瞻仅基于上一份SEC文件做历史重建，不包含 [2025Q1](https://www.sec.gov/Archives/edgar/data/1326801/000132680125000017/meta-20241231.htm) 实际结果，也不编造共识或股价判断。
