# 微软（MSFT）2025Q4（FY2026 Q2）财报分析

> 财报口径：截至 2025 年 12 月 31 日季度；发布日 2026 年 1 月 28 日。货币单位：美元。GAAP 与非 GAAP 均来自微软官方新闻稿。

## 实际结果

- 总营收 **813 亿美元**，同比 **+17%**（固定汇率 +15%）。[微软新闻稿](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q2/press-release-webcast)
- GAAP 营业利润 **383 亿美元**，同比 **+21%**（固定汇率 +19%）。
- GAAP 净利润 **385 亿美元**，同比 **+60%**；GAAP 摊薄每股收益 **5.16 美元**，同比 **+60%**。
- 非 GAAP 净利润 **309 亿美元**，同比 **+23%**（固定汇率 +21%）；非 GAAP 摊薄每股收益 **4.14 美元**，同比 **+24%**（固定汇率 +21%）。

## GAAP 与非 GAAP 差异主因：OpenAI 投资损益

GAAP 净利润增速（60%）远高于非 GAAP（23%），主要因为本季度确认了 **OpenAI 投资净收益 76 亿美元（每股约 1.02 美元）**；上年同期为净损失 9.39 亿美元（每股约 0.12 美元）。剔除该项后，非 GAAP 增速更能反映经营趋势。[非 GAAP 定义](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q2/press-release-webcast)

## 分部与产品线

### 生产力与业务流程（PBP）

营收 **341 亿美元**，同比 **+16%**（固定汇率 +14%）。
- Microsoft 365 商业云营收 +17%（固定汇率 +14%）
- Microsoft 365 消费者云营收 +29%（固定汇率 +27%）
- LinkedIn 营收 +11%（固定汇率 +10%）
- Dynamics 365 营收 +19%（固定汇率 +17%）

### 智能云（Intelligent Cloud）

营收 **329 亿美元**，同比 **+29%**（固定汇率 +28%）。
- **Azure 和其他云服务营收 +39%**（固定汇率 +38%），为主要增长引擎

### 更多个人计算（More Personal Computing）

营收 **143 亿美元**，同比 **-3%**，为唯一下滑分部。
- Windows OEM 和设备营收 +1%（固定汇率持平）
- Xbox 内容和服务营收 **-5%**（固定汇率 -6%）
- 搜索和新闻广告（不含流量获取成本）营收 +10%（固定汇率 +9%）

## 核心云指标与股东回报

- **Microsoft Cloud 营收 515 亿美元**，同比 **+26%**（固定汇率 +24%）。
- 商业剩余履约义务（商业 RPO）**6250 亿美元**，同比 **+110%**，显示未来云与 AI 合约强劲。[业务亮点](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q2/press-release-webcast)
- 本季度以股息和回购形式返还股东 **127 亿美元**，同比 **+32%**。

## 与 Preview 的复核

**无同期 Preview**：所附来源中没有财报前定稿的 Preview 文章，因此本稿不进行“预期 vs 实际”复核，仅记录官方已披露事实。

## 下一季要点

1. Azure 增速（本季 39%）能否在高基数上维持，以及固定汇率影响。
2. 商业 RPO（本季 110% 增长）的订单转化节奏。
3. Xbox 内容与服务收入负增长是否延续。
4. OpenAI 投资损益对 GAAP 净利润的后续波动。

> 数据来源：微软投资者关系 FY2026 Q2 新闻稿（2026 年 1 月 28 日发布）。
