# 历史资料重建：微软 2025 年第四季度（FY2026 Q2）财报预览

本文为历史资料重建。仅使用截至 2025 年 10 月 29 日已公开的官方信息，主要依据微软 [FY2026 第一季度财报新闻稿](https://www.microsoft.com/en-us/Investor/earnings/FY-2026-Q1/press-release-webcast)。本文不包含该日期之后的任何信息，也不构成当时实际发表的预测。

## 上季基准（FY2026 Q1，截至 2025 年 9 月 30 日）

以下数据均出自同一份[官方新闻稿](https://www.microsoft.com/en-us/Investor/earnings/FY-2026-Q1/press-release-webcast)：

- 总收入 777 亿美元，同比 +18%（固定汇率 +17%）。
- 经营利润 380 亿美元，同比 +24%（固定汇率 +22%）。
- GAAP 净利润 277 亿美元，同比 +12%；GAAP 每股收益 3.72 美元，同比 +13%。
- 剔除 OpenAI 投资损失 30.86 亿美元后，non-GAAP 净利润 308 亿美元，同比 +22%；non-GAAP 每股收益 4.13 美元，同比 +23%。
- Microsoft Cloud 收入 491 亿美元，同比 +26%（固定汇率 +25%）。
- Azure 及其他云服务收入同比 +40%（固定汇率 +39%）。
- 商业剩余履约义务（cRPO）增至 3920 亿美元，同比 +51%。

公司未在本新闻稿中给出下一季度的具体财务指引，电话会议将提供前瞻性信息。本文不引用未公开的一致预期数字。

## 本季核心问题

1. **Azure 增速能否维持在 40% 左右？** Azure 是智能云增长的主要引擎。上一季度 40% 为同比口径，新闻稿未披露环比数据。市场将关注电话会议是否给出增长展望。
2. **AI 投入与 OpenAI 损失如何影响利润？** 管理层表示将继续增加 AI 相关的资本和人才投入。Q1 中 OpenAI 投资损失使 GAAP 净利润减少 30.86 亿美元，non-GAAP 口径将其剔除。未来损失金额未知。
3. **cRPO 高增长能否延续？** cRPO 同比增长 51%，反映商业云合同的强劲预订。若增速明显回落，可能削弱市场对未来收入能见度的信心。

## 正负预期差

**潜在正面因素：**

- Azure 增速继续保持在 40% 或更高，超出公司自身的保守评论。
- Microsoft Cloud 与 Copilot 的客户采用和变现强于公开表态。
- OpenAI 投资损失小于上一季度，减轻 GAAP 利润压力。

**潜在负面因素：**

- Azure 增速出现超预期下滑，或智能云收入不及预期。
- AI 基础设施资本开支扩张快于收入增长，压缩自由现金流。
- 汇率逆风加大，固定汇率与报告增速差距扩大。
- OpenAI 投资损失进一步扩大，拖累 GAAP 每股收益。

## 财报验证点

下一份财报（FY2026 Q2）公布后，可对照核验以下项目：

- 分部门收入：生产力与业务流程、智能云、更多个人计算。
- Microsoft Cloud 与 Azure 的同比增速（及固定汇率口径）。
- cRPO 的同比变化。
- OpenAI 投资损失金额及 non-GAAP 调节项。
- 资本开支、股东回报（分红与回购）金额。
