# 微软 FY2025 全年业绩（报告期末 2025-06-30）财报后分析

**资料截止：2025-07-30 23:59 UTC｜来源：SEC 10-K（accession 000095017025100235）**

## 主要结论

本次证据对应的是**微软 FY2025 全年（2024-07-01 至 2025-06-30）10-K**，而非 2025 自然年 Q2 单季。因此本文标题按报告期末标注，不将其等同于某一财季。有条件判断：**微软 FY2025 的增长引擎已明确从传统授权软件切换为云与 AI 基础设施**——Azure 及云服务收入全年增长 34%、Microsoft Cloud 收入达 1,689 亿美元（+23%），但代价是 AI 基础设施扩张压低云毛利率（Microsoft Cloud 毛利率降至 69%）。利润与现金仍强劲（经营现金流 1,361.6 亿美元），但"高增长 + 毛利率承压 + 资本开支上行"的组合是理解本期的核心。

## 财报数据与主要产品

全年（US GAAP，非 Q4 单季）：

- 收入 **2,817.24 亿美元**（同比 +15%，原文称增加 366 亿美元）
- 经营利润 **1,285.28 亿美元**（+17%，增加 191 亿美元）
- 净利润 **1,018.32 亿美元**
- 经营现金流 **1,361.62 亿美元**

分部与产品（全年同比）：

- **智能云**：收入 +21%，其中 Server 产品与云服务 +23%，**Azure 及其他云服务 +34%**；经营利润 +18%。成本 +36%（Azure 驱动），毛利率下降，主因 AI 基础设施扩张，部分被 Azure 效率改善抵消。
- **生产力与业务流程**：收入 +13%。Microsoft 365 商用云 +15%（席位 +6%），商用产品 +7%（Office 2024 上市带动）；消费者云 +11%，订阅用户 +8% 至 **8,900 万**，并受 2025 年 1 月提价推动 ARPU；Dynamics 365 +19%；LinkedIn +9%。经营利润 +17%。
- **更多个人计算**：收入 +7%。Windows OEM 与设备 +3%（OEM 增、设备降）；Xbox 内容与服务 +16%（含 Activision 并表与 Game Pass），Xbox 硬件 -25%；搜索与新闻广告（剔除流量获取成本）+20%。经营利润 +18%。

## 利润与现金

收入增长传导至利润的路径清晰：毛利率金额 +13%，但**毛利率百分比小幅下降**，智能云是主要拖累，更多个人计算部分抵消；经营费用仅 +6%（低于收入增速），使经营利润增速（+17%）高于收入（+15%）。费用增长主要来自云与 AI 工程及 Gaming（含 Activision）。现金端，公司称现有现金、短期投资与经营现金流足以覆盖未来至少 12 个月的经营、股息、回购、债务到期与资本开支，并明确将继续投入数据中心与 AI 基础设施。**注意：证据未给出全年资本开支、自由现金流、回购/分红总额的具体数字**（仅提及 Q4 单季向股东返还 94 亿美元），这些需查 10-K 现金流量表与股东权益附注核实。

## 本季核心问题（无同期 Preview）

数据库无同期 Preview，故不作预测复核，改写为本期核心问题：**AI 基础设施投入是否在侵蚀云业务盈利质量？** 实际结果显示：Azure 增速（34%）与 Microsoft Cloud 规模（1,689 亿美元）验证需求强劲，但云毛利率降至 69%、智能云成本 +36%，说明当前处于"以利润率换规模与卡位"的阶段。这是经营事实；至于该投入能否在未来转化为更高单位经济性，属推论，需后续季度毛利率走势验证。

## 下一季判断与关键验证点

判断：若 Azure 维持 30% 上下增速且云毛利率企稳，则"投入换增长"逻辑成立；若毛利率继续下滑而增速放缓，则盈利质量风险上升。关键验证点：

1. 下一季 Azure 增速与 Microsoft Cloud 毛利率是否止跌；
2. 资本开支与自由现金流（本期证据缺失，需查现金流量表）；
3. Microsoft 365 商用席位与 ARPU（提价后是否影响续订）；
4. Xbox 硬件下滑与内容服务增长的净效应；
5. 关税、AI 出口管制（如 AI Diffusion Rule）对供应链与云成本的实际影响。
