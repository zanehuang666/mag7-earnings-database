# 微软 FY2025 全年业绩后分析（资料截止 2025-07-30）

## 主要结论

本次可核验的官方数据仅覆盖**微软 2025 财年全年（2024-07-01 至 2025-06-30）**，而非 2025 自然年 Q2 单季。基于全年口径，微软 FY2025 收入 2,817.24 亿美元、营业利润 1,285.28 亿美元、净利润 1,018.32 亿美元、经营现金流 1,361.62 亿美元，营业利润率约 45.6%、净利率约 36.1%。**有条件判断**：在缺乏单季与分部数据的前提下，全年利润与现金的绝对水平仍显示核心业务的强变现能力，但"AI 与云投入是否已开始侵蚀利润率、增速是否放缓"这类关键问题，本批证据无法回答，需以 10-K 分部附注与后续 10-Q 补齐。

## 利润与现金

全年营业利润率约 45.6%、净利率约 36.1%，经营现金流（1,361.62 亿）高于净利润（1,018.32 亿），差额约 343 亿美元，通常来自折旧摊销等非现金项目及营运资本变动——但具体构成需查 10-K 现金流量表，本批证据未提供。原文强调云的规模经济（数据中心单位成本、需求聚合、多租户降低维护人力）与"安全优先"定位，这些是利润率的结构性支撑逻辑，但**属于公司叙述而非本季量化结果**，不能直接当作利润率改善的证据。

## Preview 判断复核

本季**无同期 Preview**（preview_status: no contemporaneous preview），故不做逐项预测比对。改写为本季核心问题：FY2025 全年收入与利润的绝对规模已确认，但**增长质量与结构**未确认——Azure 增速、Microsoft 365 Copilot 的付费渗透、AI 相关资本开支对自由现金流的影响，均需分部与单季数据才能判断。

## 下一季判断与关键验证点

在仅有全年数据的条件下，对 FY2026 开局（对应 2025 自然年 Q3/Q4）不宜给出方向性预测。需优先核查：

1. **分部收入与增速**：10-K 附注 18（分部信息）中三大分部各自收入及同比，尤其 Azure 与 Microsoft 365 Commercial cloud 增速；
2. **AI 资本开支**：10-K 现金流量表"购置固定资产"及管理层对数据中心投入的表述，判断经营现金流向自由现金流的转化率；
3. **单季数据**：后续 10-Q 的 Q1 FY2026 单季收入、营业利润，验证全年利润率是否可持续；
4. **分部口径调整影响**：因 FY2025 起分部重构，需确认同比基数是否重述。
