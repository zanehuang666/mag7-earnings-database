# 微软（MSFT）2026财年第三季度（截至2026年3月31日）财报分析

> 数据来源：[微软官方投资者关系新闻稿](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q3/press-release-webcast)。本稿为财报后复核；**无同期 Preview**，因此无法与任何财报前分析文章做预期差核对。

## 总览

截至2026年3月31日的季度，微软营收828.86亿美元，同比增长18%，固定汇率增长15%；经营利润383.98亿美元，同比增长20%（固定汇率16%）。GAAP净利润317.78亿美元，同比增长23%；non-GAAP净利润317.92亿美元，同比增长20%（固定汇率18%）。GAAP摊薄EPS为4.27美元，同比增长23%；non-GAAP EPS同比增长21%（固定汇率18%）。按新闻稿的固定汇率调节表，汇率对美元收入增速形成约3个百分点的正贡献（约20.7亿美元），因此趋势判断应同时参考固定汇率口径。

管理层表示收入、经营利润和EPS超出预期；本稿未取得独立市场共识，故将该表述视为公司口径，不视为外部预期差验证。

## 分部与产品

- 生产力与业务流程：350.13亿美元，+17%（固定汇率+13%）。Microsoft 365商业云+19%（+15%），消费者云+33%（+29%），LinkedIn +12%（+9%），Dynamics 365 +22%（+17%）。
- 智能云：346.81亿美元，+30%（固定汇率+28%）；Azure和其他云服务+40%（固定汇率+39%），是主要增长拉动。
- 更多个人计算：131.92亿美元，-1%（固定汇率-3%）；Windows OEM和设备-2%，Xbox内容和服务-5%，搜索广告（扣除流量获取成本）+12%。

## 云、AI与现金流

Microsoft Cloud营收545亿美元，同比增长29%（固定汇率25%）。商业剩余履约义务（cRPO）同比增加99%至6,270亿美元，为后续云收入确认提供较强的在手合同支撑。CEO Satya Nadella表示，AI业务年化收入运行率已超过370亿美元，同比增长123%；新闻稿未给出该口径的细项定义，因此不直接与GAAP分部收入挂钩。

利润与现金方面，经营利润报告增速（+20%）快于营收报告增速（+18%）。OpenAI投资净损失为1,400万美元，远低于去年同期的5.83亿美元，对non-GAAP EPS几乎无摊薄。本季度以股息和回购形式向股东返还102亿美元。

## 原判断复核与下一季要点

本季度没有可用的同期Preview，因此不进行预期差复核。新闻稿未给出下季数字指引，公司将在电话会议上提供前瞻指引。下一季可关注：Azure增速能否维持40%左右，Microsoft Cloud在固定汇率下能否延续25%左右的增速，cRPO高增长向收入的转化，以及Xbox内容和服务增速能否回升。
