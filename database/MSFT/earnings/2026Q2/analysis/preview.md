# 历史资料重建：微软（MSFT）2026年日历Q2（FY26Q4）财报前瞻

> 本文为历史资料重建，仅依据 2026年4月29日发布的 [FY26Q3新闻稿](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q3/press-release-webcast) 撰写；不代表当时真实预测，也未使用该季度财报发布后的任何信息。截至资料截止日，新闻稿未给出 FY26Q4 量化指引，只表示管理层将在电话会上提供前瞻信息。

## 结论
- 上季营收 $82.886B，同比 +18%（固定汇率 +15%）；经营利润 $38.398B，+20%（固定汇率 +16%）。增长主要由云和 AI 驱动。
- AI 业务年化收入运行率超 $37B，同比 +123%；Microsoft Cloud 收入 $54.5B，+29%（固定汇率 +25%）。
- 下一季最需确认 Azure 约 40% 的增速能否延续、商业剩余履约义务 $627B（+99%）能否加快转化为云收入，以及 More Personal Computing 的弱势是否扩大。

## 上季基准（FY26Q3，截至2026年3月31日）
- GAAP 净利 $31.778B，+23%；non-GAAP 净利 $31.792B，+20%；GAAP/非GAAP 摊薄 EPS 均为 $4.27（+23% / +21%）。
- 分部：PBP $35.0B，+17%；IC $34.7B，+30%；MPC $13.2B，-1%。
- 细分：Azure and other cloud services +40%（固定汇率 +39%）；Windows OEM and Devices -2%；Xbox content and services -5%；搜索广告（不含流量获取成本）+12%。

## 本季核心问题
1. Azure +40% 能否持续：上季增速受 AI 容量和企业需求拉动，下一季需观察是否有产能或交付瓶颈。
2. 商业 backlog 的确认节奏：$627B 的 RPO 增长 99%，但转化为 Microsoft Cloud 收入的时间和期限结构决定本季收入。
3. MPC 是否继续拖累：Windows OEM/Devices 和 Xbox content/services 均下滑，若消费硬件与游戏内容需求继续走弱，会部分抵消云业务增长。

## 正负预期差
- 正：AI 运行率超 $37B 且 +123%；Microsoft Cloud 与两大商业分部均双位数增长；RPO 接近翻倍，收入可见度高。
- 负：MPC 整体 -1%，游戏和 Windows OEM/Devices 负增长；上季 GAAP 增速高于固定汇率，汇率波动可能改变同比口径；OpenAI 投资净损失上季仅 $14M（上年同期 $583M），若未来波动会同时影响 GAAP/非GAAP 净利（但不能据此推断下一季）。

## 财报验证点
- Azure and other cloud services 增速对比 40%（固定汇率 39%）。
- Microsoft Cloud 收入增速对比 29%（固定汇率 25%）。
- 商业 RPO 增速对比 99%。
- 分部增速：PBP 17%、IC 30%、MPC -1%。
- AI 业务年化收入运行率超 $37B 及 +123%。
- OpenAI 投资影响及 GAAP/非GAAP 净利、EPS。
- 汇率影响：GAAP 与固定汇率增速的差异。
