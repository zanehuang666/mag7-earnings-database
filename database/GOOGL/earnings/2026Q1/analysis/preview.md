# 历史资料重建：Alphabet（GOOGL）2026Q1 财报预览

> 本文是历史资料重建，不是当时实际发表的预测。写作所用资料截至 2026-02-04 23:59:59，即 Alphabet 发布 2025Q4 财报当日；所有数字均来自 [Alphabet 2025Q4 官方财报](https://s206.q4cdn.com/479360582/files/doc_news/2026/Feb/04/attachments/2025q4-alphabet-earnings-release.pdf)。本预览只用该季度财报前已公开的信息，不使用 2026Q1 财报后的任何信息。

## 上季基准：2025Q4（截至 2025-12-31）

- 合并收入 1138 亿美元，同比 +18%，固定汇率 +17%。
- Google Services 收入 959 亿美元，同比 +14%。其中 Search 及其他收入 631 亿美元（+17%）；YouTube 广告收入 114 亿美元（+9%）；订阅、平台和设备收入 136 亿美元（+17%）。
- Google Cloud 收入 177 亿美元，同比 +48%。公司称 2025 年底 Cloud 年化运行率超过 700 亿美元。
- 合并营业利润 359 亿美元，营业利润率 31.6%（财报正文口径；表格四舍五入为 32%）；净利润 345 亿美元，摊薄 EPS 2.82 美元。
- 业绩包含 21 亿美元 Waymo 员工薪酬费用。公司同时披露，Waymo 在 2026 年 2 月宣布 160 亿美元融资，绝大部分由 Alphabet 出资。
- 管理层披露 2026 年资本开支预期为 1750 亿至 1850 亿美元。

## 本季两三个核心问题

1. **Cloud 高增长能否持续至 2026Q1？** 公司把 Cloud +48% 归因于企业 AI 基础设施和 AI 解决方案，以及核心 GCP 产品。Q1 将检验这个增速是否能在高基数上延续。
2. **高资本开支对利润率的影响有多大？** 2026 年资本开支指引 1750–1850 亿美元，远高于日常水平；折旧和研发投入可能压低营业利润率。Q1 的 Alphabet-level 活动亏损可作为观察点。
3. **Waymo 亏损与股权薪酬是否继续扩大？** Other Bets 的 Q4 营业亏损从 11.7 亿美元扩大到 36.2 亿美元；Alphabet-level 活动亏损从 27.8 亿美元扩大到 58.9 亿美元。Q1 需看是否延续。

## 正负预期差

可从公开资料观察的正面因素：Gemini 3 发布；第一方模型经 API 直接处理超过每分钟 100 亿 token；Gemini App 月活超 7.5 亿；消费者付费订阅超 3.25 亿；YouTube 全年广告加订阅收入超过 600 亿美元。

负面因素：Google Network 收入同比下滑（Q4 从 79.5 亿美元降至 78.3 亿美元）；Other Bets 与 Alphabet-level 活动亏损扩大；超大型资本开支可能压低利润率；固定汇率增速低于名义增速，汇率存在拖累。

## 财报验证点

- 合并收入增速、固定汇率增速，以及 Google Services/Cloud/Other Bets 分部收入。
- 合并营业利润率与 Alphabet-level 活动费用是否继续上升。
- 管理层是否给出 2026Q1 或全年资本开支的新表述。
- Other Bets 亏损、Waymo 相关费用或融资相关披露是否延续。
