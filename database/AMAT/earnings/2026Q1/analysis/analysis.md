# Applied Materials（AMAT）FY2026 第一季度财报后分析

**资料截止：2026-02-19；报告期末：2026-01-25（公司财年 2026 第一季度）**

## 主要结论

本季是一份“收入承压、利润率被一次性法律费用压住、但现金与净利仍强”的财报。收入 70.12 亿美元，同比走弱，主因是半导体系统（Semiconductor Systems）中成熟制程逻辑需求下降；AGS 服务与备件增长部分对冲。经营利润 18.31 亿美元，但其中已计入 2.53 亿美元 BIS 出口管制和解费用，若剔除该项，经营利润率将明显高于表观水平。净利润 20.26 亿美元高于经营利润，说明非经营项（权益投资净收益等）贡献显著，属“经营事实之外的推论需谨慎”的部分。经营现金流 16.86 亿美元，资本开支 6.46 亿美元，现金转化仍健康。

## 财报数据与主要产品

- 收入：70.12 亿美元（2025-10-27 至 2026-01-25）[来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)
- 经营利润：18.31 亿美元（同上）
- 净利润：20.26 亿美元（同上）
- 经营现金流：16.86 亿美元（同上）
- 资本开支：6.46 亿美元（原文现金流与分部表均列示）
- 毛利率：49.0%，同比提升 0.2 个百分点，原文归因于平均售价上升、材料与制造成本下降，部分被收入下降和客户/产品结构不利抵消。

分部层面：Semiconductor Systems 收入 51.41 亿美元，占比 73%，同比下降 8%；AGS 收入同比增长，主因长期服务协议收入与备件支出增加。原文明确：代工与逻辑客户支出下降（成熟制程逻辑系统需求减少），存储客户支出上升（DRAM 技术迁移投资增加）。本季起公司将 200mm 设备业务从 AGS 划入 Semiconductor Systems，并全额分摊公司支持成本，前期分部数据已重述——比较分部数据时须注意口径变化。

客户集中度：两家客户分别占收入约 19% 和 16%。

## 利润与现金

表观经营利润率被一次性项目压低。原文披露：2026-02-11（期末之后）与 BIS 达成和解，支付 2.53 亿美元，并在本季“legal settlement”中计提，同时确认相应负债。Semiconductor Systems 经营利润率 27.8%，同比下降 5.6 个百分点，原文归因于该法律和解费用、收入下降和研发费用上升，部分被售价上升与成本下降抵消。AGS 经营利润率同比上升，因服务与备件收入增加。

净利润高于经营利润，原文解释“利息及其他收入（费用）净额”同比增加，主因权益投资净收益上升，部分被市场利率下降导致的利息收入减少抵消。这意味着净利含较大非经营成分，不宜直接当作经营改善信号。

现金方面：经营现金流 16.86 亿美元；投资活动净流出 7.80 亿美元（资本开支 6.46 亿 + 投资净购买 1.34 亿）。应收账款周转天数由 76 天降至 65 天，原文归因于回款改善。另需注意：本季起新加坡全球最低税开始实施，原文预计将“实质性”提高海外税负，这是未来利润与现金流的持续拖累项。

## 本季核心问题（无同期 Preview）

本季无同期 Preview，故不做事后重建式比较。核心问题应聚焦三点：一是成熟制程逻辑需求下滑是否见底，存储（DRAM）投资能否持续对冲；二是 2.53 亿美元和解与全球最低税对后续利润率的持续影响；三是服务业务（AGS）能否继续提供收入与利润的稳定性。

## 下一季判断与关键验证点

判断（有条件）：若存储客户 DRAM 投资延续、AGS 服务收入保持增长，且无新增一次性法律费用，则经营利润率有望环比修复；但成熟制程逻辑疲软与新加坡税负上升会限制修复幅度。

关键验证点：
1. 下一季 Semiconductor Systems 中代工/逻辑与存储的收入结构变化，确认成熟制程是否止跌。
2. 是否还有与出口管制相关的追加费用或合规成本。
3. 全球最低税对实际税率的具体影响幅度。
4. AGS 长期服务协议与备件收入的持续性。
5. 资本开支节奏与经营现金流转化。

尚待核实：公司未在本节选中提供下一季收入/利润指引、共识预期或市场反应数据，需查原始 10-Q 全文及业绩发布材料确认。
