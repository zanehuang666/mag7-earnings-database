# AMAT 2026 财年 Q1 财报后分析

资料截止：2026-02-19T23:59:59Z；主要来源：[SEC filing](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。

## 主要结论

有条件判断：AMAT 本季不是收入扩张型财报，而是“营收小幅收缩、盈利靠毛利率与税率支撑”。营收 70.12 亿美元，同比 -2%（对比 71.66 亿美元）[来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。但营业利润 18.31 亿美元、净利 20.26 亿美元、经营现金流 16.86 亿美元，显示 AGS 服务收入和成本改善缓冲了设备周期。若 memory/DRAM 投资延续、foundry/logic 不进一步恶化，下季利润可维持韧性；若 trailing edge logic 疲弱扩散或毛利率改善被 mix 抵消，利润和现金将承压。关键不确定性：无官方指引、无分部利润数字、无现金细项。

## 财报数据和主要产品

- 营收 7,012 百万美元，季度为 2025-10-27 至 2026-01-25，同比 -2%，上年同期 7,166 百万美元 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- 客户集中度高：两个客户分别约占收入 19% 和 16% [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- Semiconductor Systems 收入同比下降；foundry/logic 客户支出下降，主因 trailing edge logic 系统需求减少；memory 客户支出增加，主因 DRAM 技术转换投资 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- AGS 收入同比增加，主因长期服务协议收入和客户备件支出增加 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- 地理上，台湾和东南亚客户收入增加，其他地区下降，主因半导体设备投资变化 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- 具体分部收入、产品线收入和地区收入数字未在证据中给出，待查。

## 利润与现金

- 营业利润 1,831 百万美元 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)；净利 2,026 百万美元 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- 毛利率同比上升，主因平均售价提高和材料/制造成本下降，部分被收入下降和不利客户/产品组合抵消；具体毛利率未披露 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。
- 有效税率 13.0%，上年同期 44.1%；下降主因 2026 年美国发生研发成本的即时费用化，以及 2025 年新加坡新税收激励协议相关的递延税资产重估 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。这对净利有支撑，但净利高于营业利润，非经营项目仍需核对。
- 经营现金流 1,686 百万美元 [来源](https://www.sec.gov/Archives/edgar/data/6951/000162828026009694/amat-20260125.htm)。资本开支、回购、分红、营运资本变化未在证据中给出，无法判断现金转换质量。

## Preview 判断复核

无同期 Preview，因此不作事后比较。改写为本季核心问题：营收同比 -2% 时，利润为何仍强？证据显示两点：毛利率同比改善、有效税率大幅下降；AGS 增长和 memory/DRAM 投资提供结构缓冲。偏差风险在于 foundry/logic 尤其是 trailing edge logic 下滑，若继续，可能抵消 memory 和 AGS。需核对：毛利率具体值、营业费用、分部利润、非经营项目、低税率可持续性。

## 下一季判断与关键验证点

在无指引证据下，不给出数字预测。基线情形是：AGS 与 memory/DRAM 投资支撑收入，毛利率若维持 ASP/成本红利，营业利润可保持韧性；但 foundry/logic 疲弱和客户集中（19%+16%）是下行风险。关键验证点：

1. 官方下季指引、毛利率和营业费用指引；
2. Semiconductor Systems 中 foundry/logic 与 memory 收入变化，DRAM 投资是否延续；
3. AGS 增长是否由长期服务协议持续驱动；
4. 有效税率 13.0% 是否一次性，非经营项目为何使净利高于营业利润；
5. 经营现金流细项、资本开支、回购、库存/应收，确认现金质量；
6. 台湾/东南亚增长与其他地区下降是否延续。

待查：分部利润、地区收入具体数字、积压订单、资本开支、共识、市场反应。
