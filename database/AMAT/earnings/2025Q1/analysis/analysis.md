# Applied Materials（AMAT）FY2025 第一财季（截至 2025-01-26）财报后分析

**资料截止：2025-02-20 23:59:59 UTC｜来源：公司 FY2025 Q1 Form 10-Q（SEC，accession 0000006951-25-000011）**

## 主要结论

本季是一份“收入与毛利率改善、但净利润被非经营与税项显著稀释”的季度。收入 71.66 亿美元、经营利润 21.75 亿美元，经营层面表现稳健；毛利率同比提升 1.0 个百分点至 48.8%，公司归因于客户与产品结构改善及材料/制造成本下降。但净利润仅 11.85 亿美元，与经营利润之间存在约 9.9 亿美元落差，主要来自有效税率从 12.3% 跳升至 44.1%，以及权益投资净亏损扩大。经营现金流 9.25 亿美元，低于净利润，且资本开支同比升至 3.81 亿美元，自由现金流承压。**判断：本季利润质量的核心矛盾不在主营，而在税项与非经营项目；下一季需验证税率是否回归常态、以及半导体系统分部动能能否延续。**

## 财报数据与主要产品

- 收入 71.66 亿美元（2024-10-28 至 2025-01-26，US GAAP）。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000011/amat-20250126.htm)
- 经营利润 21.75 亿美元；净利润 11.85 亿美元；经营现金流 9.25 亿美元（同上期间）。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000011/amat-20250126.htm)
- 毛利率 48.8%，同比 +1.0 个百分点，原文归因于“客户与产品结构有利变化、材料与制造成本下降”。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000011/amat-20250126.htm)
- 分部：Semiconductor Systems 收入 53.56 亿美元，占比 75%，同比 +9%；经营利润率 37.1%，同比 +1.6 个百分点。AGS 收入同比增长，主要来自长期服务协议与备件支出增加，部分被 200mm 设备支出下降抵消；AGS 经营利润率同比小幅下降，因 200mm 收入减少及存货过剩/陈旧费用上升。Display 收入同比下降，因终端需求疲弱下客户减少显示制造设备投资。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000011/amat-20250126.htm)
- 终端结构：代工/逻辑客户支出同比增加（领先制程投资），存储客户支出同比下降（DRAM 技术转换投资减少）。地区上，韩国、台湾收入增长，中国收入下降（半导体设备投资减少，部分被备件与服务抵消）；约 87% 收入来自美国以外。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000011/amat-20250126.htm)

## 利润与现金

经营利润 21.75 亿美元对应 30.4% 的经营利润率，主营盈利能力并未恶化。净利润与经营利润的缺口主要来自两项：一是有效税率升至 44.1%（上年同期 12.3%），原文明确说明本季税率“更高”；二是“利息及其他收入（费用）净额”同比下降，主因权益投资净亏损扩大（部分被利息收入增加抵消）。这意味着本季 EPS 层面的弱势更多是税项与投资损益扰动，而非设备主业走弱。

现金端：经营现金流 9.25 亿美元，明显低于净利润，需关注营运资本变动细节（原文未在节选中给出完整调节表）。投资活动净流出 8.97 亿美元，其中资本开支 3.81 亿美元（上年同期 2.29 亿美元）、投资购买净额 4.88 亿美元、收购净支出 0.28 亿美元。资本开支同比大幅上升，是自由现金流的主要拖累项。此外，本季确认了约 13 亿美元与期初合同负债相关的收入，说明订单转化正常。

## Preview 判断复核

本季无同期 Preview（preview_status = no contemporaneous preview），故不做事后重建式比较。改写为本季核心问题：**在存储客户支出走弱、中国收入下降的背景下，代工/逻辑与 AGS 服务能否支撑收入与毛利率？** 实际结果给出偏正面答案：Semiconductor Systems 同比 +9%、毛利率 +1.0 个百分点，说明领先制程投资与服务业务对冲了存储与中国拖累。但净利润被税率与投资损益显著压低，是本季最需解释的偏差来源。

## 下一季判断与关键验证点

- **税率**：44.1% 是否为一次性（如估值备抵、地域利润结构或单项税务事项）？若回归常态，净利润将向经营利润靠拢；若持续，则全年 EPS 承压。需查 10-Q 税务附注。
- **存储与 DRAM**：存储支出同比下降是否见底？需看下季存储客户资本开支指引与订单。
- **中国**：收入下降趋势是否延续，出口管制与关税风险（原文提及 2022 年以来多次收到 DOJ/BIS/SEC 传票）是否影响交付。
- **AGS 利润率**：200mm 疲弱与存货费用是否持续压制。
- **现金流**：资本开支上升与经营现金流低于净利润是否延续，需核对营运资本明细。
