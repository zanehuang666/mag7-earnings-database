# Applied Materials（AMAT）2025 财年第三季度财报后分析

**资料截止：2025-08-21 23:59:59 UTC｜财季：2025-04-28 至 2025-07-27（FY2025 Q3）｜币种：美元｜口径：US GAAP**

## 主要结论

本季 AMAT 呈现“收入温和增长、毛利率与经营利润率同步抬升”的组合：营收 73.02 亿美元，同比增长约 8%；经营利润 22.33 亿美元，同比增长约 15%，增速快于收入，说明利润改善不只是规模效应，毛利率上行是主要推手。毛利率由 47.3% 升至 48.8%（+1.5 个百分点），是本期最值得关注的经营事实。**有条件判断**：若毛利率改善可持续、且中国与韩国设备投资节奏不出现逆转，则利润与现金的韧性可延续；但本季证据未提供现金流、分部利润、指引与订单数据，尚不足以判断改善是结构性还是季度性。

## 财报数据与主要产品

- 营收：73.02 亿美元（本季），上年同期 67.78 亿美元，同比 +8%；前九个月 215.68 亿美元，上年同期 201.31 亿美元，同比 +7%。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000037/amat-20250727.htm)
- 毛利率：48.8%，上年同期 47.3%，+1.5 个百分点；前九个月 48.9%，上年同期 47.5%。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000037/amat-20250727.htm)
- 经营利润：22.33 亿美元（本季），上年同期 19.42 亿美元，+2.91 亿美元；前九个月 65.77 亿美元，上年同期 58.21 亿美元。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000037/amat-20250727.htm)
- 净利润：17.79 亿美元（本季）。[来源](https://www.sec.gov/Archives/edgar/data/6951/000000695125000037/amat-20250727.htm)

## 利润与现金

利润端：收入 +8% 而经营利润 +15%，经营杠杆为正。毛利率 +1.5 个百分点是核心变量，可能来自产品组合、定价或成本改善，但证据未说明驱动因素，**属推论而非事实**。

现金端：节选仅显示“前九个月”现金流量表标题，未给出本季经营现金流、自由现金流或资本开支数字。**现金流与资本开支尚待核实**，需查 10-Q 现金流量表正文及资本开支附注。因此无法判断本季利润向现金的转化质量。

## 本季核心问题（无同期 Preview）

本季无同期 Preview，故不做事后重建式“预测复核”。本季核心问题应转为：**毛利率 +1.5 个百分点的改善能否延续，以及收入增长的区域结构是否健康？** 原文披露：韩国收入同比增长，主因半导体设备投资、部分被显示设备支出下降抵消；中国本季收入同比增长，主因半导体设备与显示设备投资增加，但前九个月中国收入同比下降，主因半导体设备投资减少、部分被备件服务与显示设备抵消；美国与东南亚本季及前九个月均下降，主因半导体设备及 200mm 设备投资减少。区域分化明显，中国单季回升与前九个月下滑并存，需警惕季度波动。

## 下一季判断与关键验证点

**判断**：在毛利率维持 48% 以上、区域设备投资不显著恶化的前提下，下一季利润有望保持同比增长；但缺乏指引与订单证据，方向性判断置信度有限。

关键验证点：
1. 下一季毛利率是否守住 48% 以上，及公司对毛利率驱动的解释；
2. 中国收入单季回升是否延续，还是前九个月下滑趋势中的反弹；
3. 分部（Semiconductor Systems / AGS）收入与利润拆分；
4. 经营现金流、自由现金流与资本开支；
5. 客户集中度：前九个月两大客户分别占净收入约 19% 与 15%，需跟踪变化。
