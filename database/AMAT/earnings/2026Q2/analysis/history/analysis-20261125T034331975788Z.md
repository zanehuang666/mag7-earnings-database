# 应用材料（AMAT）2026 财年第二季度财报后分析

**资料截止：2026-05-21 23:59:59 UTC｜财季：2026-01-26 至 2026-04-26（FY2026 Q2）｜币种：美元｜口径：US GAAP**

## 主要结论

本季 AMAT 呈现"高收入、高营业利润率、净利高于营业利润"的组合：营收 79.1 亿美元，营业利润 25.23 亿美元（营业利润率约 31.9%），净利润 28.06 亿美元，净利高于营业利润约 2.83 亿美元，差额主要来自营业外项目（利息、投资收益、税项等），但现有证据未给出明细，无法归因。**有条件判断**：若该净利—营业利润差额来自可持续的利息/投资收益而非一次性项目，则本季盈利质量偏强；若来自一次性处置或税务调整，则经常性盈利能力应参照营业利润口径。这一区分是后续复核的核心。

## 利润与现金

营业利润率约 31.9%（25.23/79.10），属高位水平，但缺少上季与去年同期对比，**利润率环比/同比方向尚待核实**。净利高于营业利润，说明营业外净收益与税项合计为正贡献，具体构成（利息收入、股权投资损益、税率）需查利润表与附注。

现金流方面，原文节选仅出现"截至 2026-04-26 及 2025-04-27 的**六个月**合并现金流量表"标题及权益变动表片段，**未给出经营现金流、资本开支、自由现金流的具体数字**。因此本季现金创造能力、资本开支强度均**尚待核实**，需查 10-Q 现金流量表正文。请勿将半年度现金流数据误读为单季。

## Preview 判断复核

本季**无同期 Preview**（preview_status: no contemporaneous preview），故不作预测对照，改写为本季核心问题：

1. **净利高于营业利润的 2.83 亿美元差额来自何处？** 是否可持续？——决定经常性盈利判断。
2. **31.9% 的营业利润率处于什么历史位置？** 需上季及去年同期营业利润数据。
3. **收入结构**：Semiconductor Systems 与 AGS 各自贡献多少？分市场（如代工/存储/逻辑）与分地区如何？——判断增长驱动与周期位置。
4. **客户集中度**：半年度两家客户占 36%，单季是否更高？大客户订单节奏对后续季度的影响。

## 下一季判断与关键验证点

在缺少指引、分部与现金流证据的情况下，不对下季收入或利润率给出量化判断。**方向性判断**：本季营业利润率与净利水平偏高，若净利超额部分为一次性，则下季净利可能向营业利润口径回归；若为经常性利息/投资收益，则盈利中枢或维持。

关键验证点（按优先级）：
- 10-Q 利润表：营业外收支与有效税率明细，确认净利—营业利润差额性质；
- 10-Q 现金流量表：单季经营现金流、资本开支、自由现金流；
- 分部与分市场/分地区收入表：Semiconductor Systems 与 AGS 拆分、终端市场结构；
- 单季客户集中度与订单/ backlog 表述；
- 公司对下季的官方指引（若财报电话会或新闻稿给出），以及市场反应——现有证据均未包含，**尚待核实**。
