# 甲骨文（ORCL）FY2025 第三财季（截至 2025-02-28）财报后分析

**资料截止：2025-03-11 23:59:59 UTC｜来源：SEC 10-Q（accession 000095017025037143）**

## 主要结论

本季（公司 FY2025 第三财季，自然季 2024-12 至 2025-02）甲骨文录得收入 141.30 亿美元、经营利润 43.58 亿美元、净利润 29.36 亿美元。**核心判断（有条件）：利润质量本季被一项会计估计变更明显抬高——服务器与网络设备折旧年限由五年延长至六年，单季减少经营费用 1.81 亿美元、增加净利润 1.36 亿美元（约合每股 0.05 美元）。剔除该项，经营利润率与净利率均低于报表口径。** 该变更属非现金、非经营性驱动，不改变现金创造能力，但会削弱"利润率改善"这一叙事的可信度。由于证据仅覆盖顶层损益与部分附注，分部、产品线、云业务增速与资本开支明细尚待核实，本结论对业务结构变化的解释力有限。

## 利润与现金

利润端的关键变量是折旧估计变更：本季减少经营费用 1.81 亿美元、增加净利润 1.36 亿美元；前九个月累计减少费用 5.67 亿美元、增加净利润 4.42 亿美元（每股 0.16 美元基本 / 0.15 美元稀释）。这意味着**报表利润的同比改善中，有相当部分来自会计估计而非经营效率**。此外，2024 重组计划前九个月计提 2.27 亿美元（上年同期 3.36 亿美元），计划总成本上限 6.79 亿美元，属一次性项目。

现金与表外承诺方面：剩余履约义务（RPO）为 1,302 亿美元，其中约 31% 预计未来十二个月确认；截至 2025-02-28 另有 484 亿美元额外租赁承诺（主要为数据中心），预计 FY2025–FY2027 起租、期限十至十五年，**尚未反映在资产负债表上**。这指向未来资本开支与租赁负债的上升压力，是评估自由现金流的关键变量。本季经营现金流、资本开支与自由现金流的具体数字未在证据中给出，尚待核实。

## 本季核心问题（无同期 Preview）

本季无同期 Preview，故不作预测复核，改列核心问题：**在折旧年限延长与数据中心租赁承诺快速累积的双重背景下，甲骨文的利润增长有多少来自真实经营杠杆、多少来自会计与资本结构安排？** 现有证据只能确认前者被后者部分"美化"，无法量化拆分。

## 下一季判断与关键验证点

**判断（有条件）：若云服务收入占比继续上升且资本开支同步扩张，短期利润率可能承压；折旧变更的同比顺风将在后续季度延续但不再"新增"，利润同比增速或自然回落。**

需验证：① 分部收入与云服务/许可支持增速，确认增长是否由云驱动；② 经营现金流与资本开支，测算自由现金流是否被数据中心投入侵蚀；③ 484 亿美元租赁承诺的起租节奏与对应折旧、利息影响；④ RPO 转化率是否兑现 31% 的十二个月指引；⑤ 重组费用后续计提与 Ampere 权益法亏损（前九个月追加 2.25 亿美元可转债投资，账面价值 15 亿美元）对非经营损益的拖累。
