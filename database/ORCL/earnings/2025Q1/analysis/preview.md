# 历史资料重建：ORCL 2025Q1 财报前瞻

上季（截至2024年11月30日，[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017024134973/orcl-20241130.htm)）官方利润表显示，营收为 14,059,000,000 美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017024134973/orcl-20241130.htm)），营业利润为 4,220,000,000 美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017024134973/orcl-20241130.htm)），净利润为 3,151,000,000 美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017024134973/orcl-20241130.htm)）。这为上季业务与利润提供基准：收入端保持规模，利润端实现正向经营利润与净利。

针对 ORCL 2025Q1，需验证两项问题：

1. **收入动能能否延续**：上季营收为 14,059,000,000 美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017024134973/orcl-20241130.htm)）。本季应观察核心需求能否支撑相近收入规模，还是出现订单递延或需求放缓。
2. **利润转化能否保持**：上季营业利润为 4,220,000,000 美元、净利润为 3,151,000,000 美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017024134973/orcl-20241130.htm)）。本季应关注费用、投入与业务组合变化会否削弱经营利润和净利表现。

正负情形：
- **正面情形**：若需求稳定且成本纪律延续，本季收入、营业利润和净利润可能接近上季水平
