# 历史资料重建：ORCL 2025Q3 财报前瞻

上一份官方 SEC 文件给出截至 2025-05-31 的上一完整财年口径：营收 573.99 亿美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017025087926/orcl-20250531.htm)），营业利润 176.78 亿美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017025087926/orcl-20250531.htm)），净利润 124.43 亿美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017025087926/orcl-20250531.htm)），经营现金流 208.21 亿美元（[来源](https://www.sec.gov/Archives/edgar/data/1341439/000095017025087926/orcl-20250531.htm)）。这些数字是全年口径，并非单季，因此本前瞻仅将其作为业务与利润基线，不拆解 2025Q3 实际结果。业务上，ORCL 需继续把云基础设施、数据库和应用工作负载转化为收入，同时控制基础设施投入对利润与现金流的影响。

本季两个验证问题：
1. 云与 AI 相关需求的订单或剩余履约义务，能否在 Q3 更快转化为收入，并带动营收增速？
2. 在资本开支和折旧上升时，营业利润率与经营现金流能否维持全年所显示的韧性？

正负情形：
- 正面：若云需求兑现、交叉销售提升，营收增长且营业利润率和经营现金流保持稳健，全年数字所体现的盈利质量可延续。
- 负面：若客户延迟、竞争压价或基础设施投入超预期，利润率和现金流可能承压，云增长也可能慢于投入扩张。

以上为历史资料重建，不包含 2025Q3 实际结果，也不代表共识或股价判断。
