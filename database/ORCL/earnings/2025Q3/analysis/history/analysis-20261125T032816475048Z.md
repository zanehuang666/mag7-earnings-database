# ORCL 2025Q3（截至2025-08-31季度；公司 FY2026 Q1）分析

本稿仅依据所给官方 SEC 申报与 XBRL 提取事实。该季度为 2025-06-01 至 2025-08-31，按日历为 2025Q3；按 Oracle 财年则为 FY2026 第一季度。币种均为美元，口径为 US GAAP。来源为 [SEC 申报](https://www.sec.gov/Archives/edgar/data/1341439/000119312525200095/orcl-20250831.htm)。

## 核心数字

- 收入：14,926,000,000 美元。
- 营业利润：4,277,000,000 美元。
- 净利润：2,927,000,000 美元。
- 经营现金流：8,140,000,000 美元。

上述为单季数值，不是全年值，也不是财年 Q3 或 Q4 单季值。所有数字均标注“来源复核待完成”。未提供去年同期、分部、指引或资产负债表项目，因此不做同比、环比或趋势推断。

## 口径与限制

本分析没有真正的财报前同期 Preview，故不写“当时预测”。历史资料重建不适用于本稿；因为 historical_reconstruction 为 false。未提供共识、股价反应或市场预期，严禁补造。来源复核未完成时，以上数字均应视为待核。若后续核对发现差异，应以 SEC 申报原文为准。本稿不把 10-K 全年值称为 Q4 单季值；也未使用此类全年数字。
