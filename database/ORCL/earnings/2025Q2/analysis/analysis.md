# 甲骨文（ORCL）2025 财年业绩后分析

**资料截止：2025-06-18 23:59:59 UTC｜财年口径：2024-06-01 至 2025-05-31（FY2025）**

## 主要结论

本次可核验的官方数据全部为 **FY2025 全年（10-K）口径**，而非 2025 财年第四季度单季。基于全年数据，甲骨文 FY2025 呈现"收入规模稳健、经营利润率偏低、现金转化尚可"的组合：全年收入 573.99 亿美元，经营利润 176.78 亿美元（经营利润率约 30.8%），净利润 124.43 亿美元（净利率约 21.7%），经营现金流 208.21 亿美元。**条件性判断**：若云服务收入占比继续按官方披露的轨迹上行（FY2025 已达总收入 43%），则收入结构向云倾斜是明确的经营事实；但全年经营利润率能否随云规模扩大而改善，仅凭本财年数据无法确认，需下一季度分部数据验证。

| 指标（FY2025 全年） | 金额（美元） | 来源 |

业务结构上，官方原文明确甲骨文有三大业务：**云与许可（cloud and license）、硬件、服务**，各为单一经营分部。产品层面，云服务包括 Oracle Cloud Applications（OCA）与 Oracle Cloud Infrastructure（OCI）；基础设施技术涵盖 Oracle Database、MySQL、Java、中间件，以及 OCI 的计算、存储、网络与 AI 基础设施。官方披露：**FY2025 云服务收入占总收入 43%**，FY2024 为 37%、FY2023 为 32%；基础设施云服务与许可支持收入占云服务及许可支持收入的 56%（FY2024 为 54%、FY2023 为 53%）。研发投入 FY2025 为 99 亿美元（FY2024 为 89 亿、FY2023 为 86 亿）。

## 利润与现金

全年经营利润率约 30.8%、净利率约 21.7%，经营现金流 208.21 亿美元，对净利润的覆盖倍数约 1.67 倍，说明利润的现金含量尚可，但**这一比率未扣除资本开支**——云与 AI 基础设施属重资产投入，自由现金流需以经营现金流减资本开支计算，而本次证据未提供 FY2025 资本开支数字，故无法给出自由现金流判断。研发费用同比增加约 10 亿美元，是压制利润率的可识别因素之一，但无法量化其对经营利润率的具体影响。

## 本季核心问题（无同期 Preview）

本次**不存在同期 Preview**，故不做事后重建式预测复核。改写为本财年核心问题：**云收入占比从 32% 升至 43% 的结构迁移，是否已转化为经营利润率的提升？** 现有全年数据只能给出静态水平（约 30.8%），缺少 FY2024 同口径经营利润率作对比，无法判断方向。这是下一份季报最需要验证的第一问题。

## 下一季判断与关键验证点

1. **云服务收入占比**：是否延续 43% 的上升趋势，还是增速放缓；
2. **分部利润率**：云与许可、硬件、服务三大分部的收入与利润率拆分，判断云业务是否自我造血；
3. **资本开支与自由现金流**：经营现金流 208.21 亿美元对应的资本开支规模，以及自由现金流是否为正；
4. **剩余履约义务（RPO）与云合同**：官方原文提到过去三年迁移客户贡献年化云服务收入增加 43 亿美元，需核实该指标的最新口径与增速；
5. **单季数据**：本次仅有全年值，Q4 单季收入、利润、现金流均待核实。
