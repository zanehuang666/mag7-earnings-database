# ORCL 2026Q2 财报后市场分析

## ① 主要结论

Oracle 2026财年第四季度总营收192亿美元，同比增长21%；云收入（IaaS加SaaS）99亿美元，同比增长47%，其中云基础设施58亿美元，同比大增93%，云应用41亿美元，同比增长10%。GAAP每股收益1.45美元，非GAAP每股收益2.11美元。剩余履约义务（RPO）从553亿美元增至638亿美元，公司原文明确该指标为合同backlog，并非已确认收入。路透社报道称，Oracle的AI支出远超市场预期，引发对其债务增长的担忧。

## ② 核心业务变化及其机制

云基础设施收入93%的增速是核心驱动力，反映企业AI算力需求持续强劲。云应用收入仅增长10%，增长高度集中于基础设施层，应用层尚未形成同等弹性。RPO从553亿增至638亿美元，合同储备扩大，但该指标不直接转化为当期收入。路透社报道显示，Oracle在6月至8月季度新增850兆瓦容量上线，资本开支压力随之上升。容量上线是收入确认的前置条件，也是折旧与利息成本的起点，这决定了基础设施增速越快，短期利润与现金流的错配越明显。

## ③ 这些变化如何改变增长、利润、现金流的预期

营收加速增长与资本开支扩张并行。路透社指出，Oracle将2027财年调整后每股收益指引从8.05美元上调至8.10美元，并预计2027财年营收至少900亿美元。标普全球在7月下调Oracle信用评级，理由正是现金流疲弱和业务风险上升。增长预期改善的同时，自由现金流和债务负担成为利润质量的关键约束。指引上调幅度有限，说明公司自身也预期资本开支与融资成本将部分抵消收入增长带来的利润弹性。

## ④ 市场如何定价，说明股价反应和具名机构分歧

据路透社报道，Oracle股价今年以来累计下跌超过20%，但在最新财报发布后盘后交易中上涨近8%。市场分歧明显：分析师预期营收将随数据中心扩张而加速；投资者对AI资本开支和债务计划感到不安。据LSEG数据，Oracle远期市盈率约24.56倍，高于微软的20.47倍，略低于亚马逊的25.19倍。路透社还提到，Oracle面临来自CoreWeave等AI云提供商的激烈竞争。估值高于微软而增速依赖重资产投入，意味着市场对Oracle的定价更接近对AI算力供给方的定价，而非对成熟软件公司的定价，一旦容量上线或融资节奏低于预期，估值溢价将首先承压。

## ⑤ 下一季最重要的业务验证点

下一季度最关键的验证点是RPO能否继续增长，以及云基础设施收入增速是否维持。路透社数据显示，2027财年第一季度RPO已从638亿美元进一步升至664亿美元，超过Visible Alpha分析师预期的639.89亿美元。数据中心容量上线进度和自由现金流改善情况将决定市场对债务风险的定价。若资本开支继续超越现金流生成能力，信用评级压力可能加剧。
