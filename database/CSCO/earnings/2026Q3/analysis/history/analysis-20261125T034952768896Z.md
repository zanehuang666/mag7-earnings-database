# 思科（CSCO）FY2026 全年业绩后分析

**资料截止：2026-09-02**｜数据来源：SEC 10-K（accession 0000858877-26-000132，财年截至 2026-07-25）

## 主要结论

思科 FY2026 呈现"收入加速、利润率扩张、现金转化偏弱"的组合。全年收入 633.25 亿美元、同比 +12%，营业利润率由 20.8% 升至 24.3%，净利润率由 18.0% 升至 22.4%——利润增速（营业利润 +31%）显著快于收入，说明本财年利润改善主要来自收入规模效应，而非毛利率提升（毛利率实际小幅下滑）。**有条件判断**：若 FY2027 收入维持双位数增长且 AI 基础设施订单延续，利润率仍有支撑；但经营现金流仅 141.77 亿美元、明显低于净利润 132.67 亿美元之外的收入体量所隐含的水平，需核实营运资本占用（应收 +11%、库存与合同制造商余额上升）是否持续。

## 财报数据与主要产品

- **全年收入 633.25 亿美元**，同比 +12%（上年 566.54 亿）。来源：[10-K](https://www.sec.gov/Archives/edgar/data/858877/000085887726000132/csco-20260725.htm)
- **产品收入 482.95 亿美元**，同比 +16%；**服务收入基本持平**（支持服务下滑、专业服务增长对冲）。
- 分区域产品收入：美洲 +17%（美国 +18%、墨西哥 +25%、巴西 -10%）、EMEA +15%（英国 +31%）、APJC +13%（中国 +23%、日本 +16%）。
- 原文明确：美洲增长由 **Service Provider 与 Cloud 客户市场**领跑，主要受 **AI Infrastructure 解决方案**驱动。
- 产品类别合计 150.30 亿美元、同比约持平（-0.16 亿），说明增长集中在基础设施/云相关品类而非全线产品。

## 利润与现金

- **营业利润 153.68 亿美元**，营业利润率 24.3%（上年 20.8%，+3.5pts）；**净利润 132.67 亿美元**，净利率 22.4%（上年 18.0%）。
- **毛利率 64.5%**，较上年 64.9% 下滑 0.4pts；产品毛利率 66.9%（上年 68.7%）。即利润率扩张来自费用杠杆，而非毛利改善。
- 费用端：R&D 与销售费用上升（AI 投入、人员与股权激励），G&A 下降；汇率净影响使三项费用增加约 1.95 亿美元（+0.8%）。
- **经营现金流 141.77 亿美元**。应收净额 74.70 亿美元、同比 +11%（公司归因于收入增长）；剩余履约义务 467.34 亿美元、+7%；递延收入 297.81 亿美元、+3%。

**经营事实 vs 推论**：收入结构、利润率、现金流为披露事实；"AI 基础设施是主要增量"为原文表述；"现金转化偏弱源于营运资本"属推论，需以现金流量表明细验证。

## 本季核心问题（无同期 Preview）

本次无同期 Preview，故不做事后重建式对比。本财年核心问题应为：**AI 基础设施驱动的收入增长能否转化为可持续的利润与现金？** 实际结果显示利润端兑现良好（营业利润率 +3.5pts），但毛利率微降、经营现金流与利润规模不匹配，转化质量待观察。

## 下一季判断与关键验证点

1. **AI 基础设施订单与收入确认节奏**：RPO +7% 是否加速，产品 RPO +9% 能否延续。
2. **毛利率走向**：产品毛利率能否止跌，AI 硬件占比上升是否继续稀释毛利。
3. **现金转化**：应收与库存变动、经营现金流/净利润比值是否回升。
4. **服务收入**：能否摆脱持平、恢复增长。
5. 尚待核实：分部利润、资本开支、FY2027 指引、市场反应与共识——证据中均未提供，需查后续 8-K/电话会材料。
