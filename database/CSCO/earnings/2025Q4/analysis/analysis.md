# 思科（CSCO）2025 财年第一季度（截至 2025-10-25）财报后分析

**资料截止：2025-11-18 23:59:59 UTC｜口径：US GAAP，单季（2025-07-27 至 2025-10-25）**

## 主要结论

本季思科录得营收 148.83 亿美元、经营利润 33.63 亿美元、净利润 28.60 亿美元，经营现金流 32.12 亿美元。**在缺少分部、产品结构与指引证据的前提下，可确认的判断是：公司在本季实现了"利润—现金"同步为正的经营状态，且现金流（32.12 亿）高于净利润（28.60 亿），说明盈利质量未依赖应计项目堆砌。** 但这一判断是有条件的：由于本季无同期 Preview、且官方节选未提供分部与产品拆分，营收与利润的**结构性驱动（AI 订单、网络设备 vs 安全 vs 协作）无法从现有证据中归因**，需待 10-Q 正文与业绩电话会材料核实。

## 利润与现金

经营利润率约为 22.6%（33.63/148.83），净利率约 19.2%（28.60/148.83）——均为按已给数字计算，非官方披露口径。经营现金流 32.12 亿高于净利润 28.60 亿，差额约 3.52 亿，方向上是正向的现金转化。节选另显示应收账款净额从 2025-07-26 的 67 亿美元降至 2025-10-25 的 48 亿美元，**应收下降通常有利于现金回收，但需注意这可能同时反映开票节奏或回款季节性，不能单独作为需求走强的证据。** 节选还提到与收购相关的补偿费用（本季 1.10 亿 vs 上年同期 2.97 亿），以及未来可能需确认的最高 5.02 亿美元现金补偿支出——这是**未来利润的潜在负担项**，需在后续季度跟踪。

## 下一季判断与关键验证点

**判断（有条件）：** 若递延收入转化与应收回收节奏延续，下一季现金流有望维持对净利润的正向覆盖；但利润端能否延续，取决于收购补偿费用的确认节奏与收入结构。

**关键验证点：**
1. **分部与产品拆分**：10-Q 中 Americas/EMEA/APJC 及网络、安全、协作各线金额与同比——目前完全缺失。
2. **同比基数**：本季仅给单季值，需核对上年同期营收/利润以判断增速。
3. **递延收入余额与转化**：节选仅给"未来 12 个月确认占比"，需查递延收入总额及环比。
4. **收购补偿费用**：最高 5.02 亿美元的确认时点与金额。
5. **指引与市场反应**：现有证据未含公司指引或股价反应，尚待核实。
