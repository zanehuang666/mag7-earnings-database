# SanDisk（SNDK）FY2026 全年业绩后分析

**资料截止：2026-08-17 23:59 UTC｜数据口径：FY2026 全年（2025-06-28 至 2026-07-03），非单季**

## 主要结论

这份 10-K 呈现的是一次**全年级别的盈利反转**，而非单季波动：FY2026 营收 202.48 亿美元，营业利润 123.89 亿美元（营业利润率 61.3%），净利润 114.33 亿美元，经营现金流 116.71 亿美元。对照 FY2025 营收 73.55 亿美元、营业亏损 13.77 亿美元、净亏损 16.41 亿美元，公司从亏损转为高盈利。**但需明确：以上均为全年数字，本季（Q4）单季数据在现有证据中无法拆分**，因此"Q4 环比是否延续"尚待核实。有条件判断：若 FY2026 的高利润率主要由价格/产品结构驱动而非一次性项目，则现金创造能力具备延续性；反之若含一次性税项或减值转回，则需下调可持续性预期。

## 财报数据与主要产品

- 全年营收 202.48 亿美元（[来源](https://www.sec.gov/Archives/edgar/data/2023554/000162828026057406/sndk-20260703.htm)）
- 全年营业利润 123.89 亿美元，营业利润率 61.3%
- 全年净利润 114.33 亿美元，净利率 56.5%
- 全年综合收益 114.26 亿美元

原文仅给出"分地区收入"与"长期资产"表，**未提供按产品线（如 NAND、企业级 SSD、消费级）拆分的收入**，因此产品结构对利润的贡献无法量化，需查 10-K 分部附注或业绩电话会材料。

## 利润与现金

利润端：营业利润率从 FY2025 的 -18.7% 升至 61.3%，净利率从 -22.3% 升至 56.5%，改善幅度极大。有效税率 FY2026 为 12%，低于 21% 美国法定税率，原文归因于**司法辖区盈亏结构、外国衍生扣除合格收入、税收抵免及马来西亚税收假期**（该假期将于 2028–2031 年间陆续到期）。这意味着当前低税率有明确到期时间表，是未来利润的潜在压力点。

现金端：全年经营现金流 116.71 亿美元，与净利润 114.33 亿美元大体匹配，说明盈利的现金含量较高，非纯账面利润。存货从 20.79 亿美元升至 26.98 亿美元；FY2026 存货费用 9100 万美元、存货准备 1.25 亿美元，规模相对营收很小，未见大额减值拖累。外汇合约相关损失 7400 万美元计入营业成本。

## 本季核心问题（无同期 Preview）

本次无同期 Preview，故不做事后重建式比较。本季应回答的核心问题是：**FY2026 的高营业利润率是价格周期高点的一次性结果，还是可持续的结构性水平？** 现有证据只能确认全年结果，无法确认 Q4 单季的环比方向、毛利率与出货量，需查 Q4 单季损益表与产品/地区拆分。

## 下一季判断与关键验证点

判断：在缺乏单季拆分前，不宜假设 61.3% 营业利润率可线性外推至下一季；低税率（12%）受马来西亚税收假期支撑，2028 年后将逐步消退。

关键验证点：
1. Q4 单季营收、营业利润、净利润（从 10-K 或后续 10-Q 拆分）
2. 按产品线的收入与毛利率结构
3. 资本开支与产能指引（本次证据未提供）
4. 马来西亚税收假期到期对有效税率的具体影响节奏
5. 存货 26.98 亿美元是否对应需求前置或备货
