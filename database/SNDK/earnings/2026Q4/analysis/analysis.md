# SanDisk（SNDK）2026 财年第四季度财报后分析

**资料截止：2026-10-30 23:59:59 UTC｜来源：SEC 10-Q（accession 000162828026068601）**

## 主要结论

本季是一份"收入与利润同步跳升、现金转化基本跟得上"的季度：营收 110.31 亿美元，营业利润 87.80 亿美元，营业利润率约 79.6%，净利 81.01 亿美元（净利率 73.5%），经营现金流 63.63 亿美元。**判断（有条件）**：利润率的异常高位更可能来自价格/产品结构的一次性跃升，而非可持续的稳态盈利水平——因为营业利润率接近 80% 对存储硬件业务而言远超常态，且经营现金流（63.63 亿）明显低于净利（81.01 亿），说明利润中相当部分尚未转为现金。若下一季营收环比回落或存货继续上升，利润率大概率向下修正。

## 财报数据与主要产品

- 营收：110.31 亿美元（2026-07-04 至 2026-10-02，US GAAP）。
- 营业利润：87.80 亿美元；净利：81.01 亿美元。
- 同比对照：营收由上年同期 23.08 亿增至 110.31 亿，增加 87.23 亿（+378%）；净利由 1.12 亿增至 81.01 亿。
- 有效税率 13%（上年同期 10%），公司解释为司法辖区利润结构、马来西亚税收优惠（2028–2031 年陆续到期）等所致。

**产品与分部**：官方节选仅给出"分拆收入（disaggregated revenue）"表的存在，未提供具体产品线或分部数字，**尚待核实**——需查 10-Q 中该表原文，确认按产品/终端市场划分的收入构成。

## 利润与现金

利润端：营业利润率约 79.6%、净利率 73.5%，两者差距主要来自税项。成本端有一次性因素：本季计入营业成本的存货费用 2,200 万美元（上年同期 700 万）；存货准备余额 1.27 亿美元（2026-10-02）对 1.25 亿美元（2026-07-03），环比基本持平。

现金端：经营现金流 63.63 亿美元，低于净利 81.01 亿，差额约 17.4 亿，指向营运资本占用（存货由 26.98 亿升至 30.16 亿，增加约 3.18 亿）及非现金/税项因素。**推论**：这是"高利润、现金略滞后"的组合，需在下一份 10-Q 中核对应收账款与存货变动明细，判断是季节性备货还是需求转弱信号。

## 下一季判断与关键验证点

- 营收能否维持在百亿美元量级，或环比明显回落；
- 营业利润率是否从约 80% 回归，若回落幅度决定利润弹性方向；
- 存货（30.16 亿）是否继续攀升、存货准备是否上调；
- 经营现金流与净利的缺口是否收窄；
- 有效税率随马来西亚优惠到期路径的变化。

**需查项目**：10-Q 分拆收入表、分部 SG&A（本季 1.63 亿 vs 上年 1.53 亿）、资本开支与下一季指引（本次证据未含）。
