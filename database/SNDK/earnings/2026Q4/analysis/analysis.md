# SNDK 2026财年第一季度财报后市场分析

## 一、主要结论

SanDisk 2026财年第一季度（截至2026年10月2日）业绩超出华尔街预期，并上调近期指引。据 Investing.com 报道，公司当季营收110.31亿美元，超过分析师预期的107亿美元，环比增长23%；非GAAP摊薄每股收益49.51美元，高于预期的47.15美元。管理层对第二财季的营收指引为122亿至126亿美元，高于122.9亿美元的市场共识；非GAAP摊薄每股收益指引为55至57美元，同样高于54.69美元的共识。Bernstein 分析师表示，“定价和回购足以抵消成本压力”，这有望在未来支撑股价。

## 二、核心业务变化及其机制

当季收入结构呈现“边缘最大、数据中心增量最强、消费级收缩”的格局。据 Investing.com 报道，边缘部门营收为58.3亿美元，环比增长7%，是收入规模最大的分部；数据中心部门营收环比增长61%至48亿美元，企业客户扩大了面向AI模型和上下文缓存的高密度闪存部署，是增量弹性最大的部门；消费级内存营收环比下降29%至3.97亿美元。非GAAP毛利率攀升至85.1%，反映出持续的定价能力。公司同期动用50亿美元回购约320万股，并批准8拆1的远期股票拆分，将于2026年11月19日收盘后生效。

## 三、这些变化如何改变增长、利润、现金流的预期

数据中心需求的爆发式增长正在重塑公司的增长曲线和利润率结构。85.1%的非GAAP毛利率意味着当前供需格局下公司拥有极强的定价权，而这一利润率水平能否持续，取决于产能约束和溢价定价能维持多久。现金流方面，据公司SEC文件，当季运营现金流为63.63亿美元；据 Investing.com 报道，同期调整后自由现金流为57亿美元。两者口径不同，不宜直接并列比较。管理层给出的第二财季营收和每股收益指引均高于共识，表明公司预计当前的增长和利润率动能至少还能延续一个季度。

## 四、市场如何定价

尽管业绩和指引双双超预期，股价在盘前交易中仍下跌3.5%。Investing.com 将此解读为过去十二个月累计上涨550%之后的某种整固。机构观点方面，Bernstein 认为定价和回购将支撑股价。但 MarketWatch 报道指出，SanDisk 的远期市盈率仅为3.04倍，远低于自2025年2月从西部数据分拆以来的10.47倍平均值；该报道同时提示，分析师认为这种低估值本身可能是“red flag”，即市场可能在定价周期见顶风险，而非单纯低估。市场定价与基本面之间的分歧，核心在于投资者对当前超高利润率可持续性的怀疑。

## 五、下一季最重要的业务验证点

下一财季最关键的验证点有三个：第一，数据中心营收能否在61%的环比增速基础上继续扩张，还是增速将显著放缓；第二，消费级内存营收环比下降29%之后能否企稳；第三，85.1%的非GAAP毛利率在产能约束和定价动态变化下能否守住。这三个变量将共同决定当前估值折价是市场误判还是合理定价。
