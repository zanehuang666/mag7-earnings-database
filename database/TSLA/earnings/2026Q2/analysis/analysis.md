# TSLA 2026Q2 财报后市场分析

## ①主要结论

特斯拉2026年第二季度营收同比增长26%至282.36亿美元，GAAP毛利率16.8%，但自由现金流为负10.92亿美元，为两年多来首次出现现金消耗。官方财报显示，当季运营现金流46.97亿美元，资本开支57.89亿美元，资本开支超过运营现金流，直接导致自由现金流为负。路透社将这一表现置于马斯克将战略重心转向人工智能、Robotaxi和下一代制造的背景下，称其汽车业务引擎正承受压力。

## ②核心业务变化及其机制

路透社援引数据称，特斯拉第二季度交付480,126辆汽车，高于华尔街预期，且较上年同期的384,122辆明显增长。当季产量为451,758辆，交付量超过产量逾28,000辆，逆转了今年早些时候的库存积累趋势。但路透社同时指出，分析师对二季度反弹究竟代表可持续需求，还是弱一季度之后的时间效应，仍存在分歧。公司通过推出低价版本以及六座版Model Y来刺激需求，汽车业务仍高度依赖Model 3和Model Y走量。

能源存储业务成为关键对冲：当季部署13.5 GWh，高于第一季度的8.8 GWh和上年同期的9.6 GWh。路透社称，该业务受益于电网级电池需求，已成为汽车业务的重要平衡力量。

## ③这些变化如何改变增长、利润、现金流的预期

路透社援引Visible Alpha数据称，华尔街预计特斯拉2026年全年交付约170万辆，意味着较去年增长，但分析师对增长能否兑现看法不一。GAAP毛利率16.8%反映定价压力持续。负自由现金流与资本开支激增表明，公司正将现金大量投入AI基础设施、电池产能、Robotaxi和下一代制造。路透社援引LSEG数据称，分析师此前预期第二季度现金消耗为33亿美元，实际负自由现金流为11亿美元，消耗幅度小于预期。能源存储业务的增长为整体利润提供一定缓冲，但汽车业务仍是主要销量和营收来源。

## ④市场如何定价

路透社报道，特斯拉股价今年迄今已下跌超过15%。路透社指出，特斯拉市值约1.4万亿美元，仍是全球市值最高的汽车制造商，这反映投资者预期自动驾驶软件、能源存储、Robotaxi和人形机器人最终能带来比汽车销售更高利润的增长。换言之，当前定价的主要依据并非汽车业务的当期现金流，而是对上述新业务的远期预期。路透社还提到，第三季度增长将面临去年同期强劲表现的高门槛。

## ⑤下一季最重要的业务验证点

路透社报道，投资者日益关注马斯克在自动驾驶和机器人领域的推进，寻求特斯拉自动驾驶叙事从承诺转向商业现实的更清晰证据。关键验证点包括：Robotaxi服务在奥斯汀、达拉斯、休斯顿、迈阿密等城市的扩张进展；欧洲范围内Full Self-Driving Supervised技术的批准投票预计今年晚些时候进行；以及能源存储部署能否维持增长势头。这些因素将决定市场是否继续给予特斯拉超越传统汽车制造商的估值溢价。
